## ขอบเขตของฉบับนี้

มีเนื้อหาบท 1–15 ภาพถ่าย PCB สำหรับอธิบายจาก Lexus Body ECU, BMW FRM และ GM BCM รวมทั้งภาพวาดหน้าที่และสัญญาณ 5 ภาพจากเอกสารผู้ผลิตชิป/กระบวนการของผู้เรียบเรียง ภาพปกเป็นภาพประกอบสร้างด้วย AI ไม่ใช่ภาพยืนยันโมดูลตรงรุ่น

กรณีรถในตารางเครื่องมือเป็นหลักฐานการรองรับในเอกสาร ไม่ใช่รายงาน full clone สำเร็จ ไม่มีการแต่งผลวัดเฉพาะรถ หมายเลขขาปลั๊ก หรือไฟล์พร้อมเขียนลงกล่อง ภาพจริงบางชุดไม่มีฉลากและ PCB สองด้านสัมพันธ์กัน จึงยังไม่ใช้สร้างใบเฉลยต่อสายเฉพาะรุ่น


## วิธีสร้างใหม่

ใช้ Python 3 พร้อม `reportlab`, `Pillow`, `pypdf` และฟอนต์ไทย Tahoma หรือฟอนต์ไทยที่กำหนดผ่านตัวแปรด้านล่าง สคริปต์ไม่มีการดาวน์โหลดระหว่างสร้าง

```powershell
python tools/build_book.py
python tools/validate.py
```

ถ้าไม่มีฟอนต์ Windows เดิม:

```powershell
$env:MYTECH_FONT_REGULAR = 'C:/path/to/Thai-Regular.ttf'
$env:MYTECH_FONT_BOLD = 'C:/path/to/Thai-Bold.ttf'
python tools/build_book.py
```

ตรวจภาพหน้า PDF ทุกครั้งเมื่อเปลี่ยนเนื้อหาหรือฟอนต์ ผลตรวจขอบเขตข้อความไม่ทดแทนการเปิดดูหน้า PDF

## สิทธิ์และการนำไปใช้

หนังสือแจกให้อ่านฟรี ไม่ได้ประกาศให้ภาพจากบุคคลอื่นเป็น public domain หรืออนุญาตใช้ซ้ำแบบรวม เจ้าของภาพและแหล่งเดิมระบุใน VISUAL_SOURCES.md รวมถึงภาพ GM ที่สงวนสิทธิ์ ผู้ประสงค์นำภาพไปใช้ซ้ำควรติดต่อเจ้าของภาพ ภาพวาดใหม่ต้องคงคำอ้างอิงและข้อความบอกขอบเขต ส่วนเอกสารผู้แต่งเดิมคงตามต้นฉบับที่เจ้าของหนังสือให้ใช้
