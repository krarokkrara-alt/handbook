# ผลตรวจหนังสือ BCM

## อัปเดตฉบับ 2 วันที่ 19 พฤศจิกายน 2569

ข้อมูลต่อจากหัวข้อนี้เป็นบันทึกฉบับแรก ฉบับ 2 เพิ่ม supplement-v2.md วงจร datasheet 8 ภาพและแผนที่ขา SPI เพิ่มภาพหน้าจอ CG-PRO/ACDP จริง ตารางเปรียบเทียบวิธีและวิเคราะห์ดีเสีย ย้ายเอกสารผู้แต่งเดิมสี่หน้าไว้หลังปก PDF หน้า 2–5 และตรวจ streams ให้ตรงต้นฉบับ สารบัญ/บุ๊กมาร์กคำนวณตามลำดับใหม่ จำนวนหน้าล่าสุดดู BUILD_REPORT.json

การตรวจอิสระพบและให้แก้ภาพกับข้อความ reset คนละชิป และรูปต่อ ACDP XDT256 ในหัวข้อ XEQ384 ต้องระบุว่าเป็นคนละฮาร์ดแวร์ ผลปิดประเด็นและขอบเขตการตรวจอยู่ EDITORIAL_REVIEW_V2.md ผลตรวจนี้เป็นการตรวจเอกสาร ไม่ใช่การทดสอบซ่อมบนรถจริงหรือการรับรองวิชาชีพ

## เนื้อหาและเทคนิค

ครบบท 1–15 ตามโครง พร้อมภาพถ่ายศึกษาบอร์ด 3 ภูมิภาค ภาพวาดหน้าที่ 5 ภาพ สารบัญ PDF และ bookmarks เอกสารผู้แต่งเดิมแนบครบ 4 หน้า ตรวจรหัสผู้แต่งกับต้นฉบับเดิมโดยไม่เพิ่มประวัติ

Agent ตรวจ pinout TCAN1042V-Q1, TJA1021 SO8 และ M95640-A125/A145 SO8 กับเอกสารผู้ผลิตแล้ว แก้ชื่อรุ่น EEPROM ให้ตรงเอกสาร เพิ่มว่า VIO เป็นไฟเลี้ยงขาเข้า และเพิ่มคำกำกับว่าเส้นในภาพแสดงความสัมพันธ์ ไม่ใช่ตำแหน่งขาทางกายภาพ

ตรวจความต่างระหว่าง coverage/read-write กับ full clone และคงข้อจำกัดไว้ในกรณีญี่ปุ่น ยุโรป อเมริกา ไม่มีการอ้างผลซ่อมของ MyTech ที่ไม่มีหลักฐาน โจทย์วิเคราะห์เพิ่มเติมระบุว่าเป็นแบบฝึก ไม่ใช่ผลวัดจริง

## การจัดหน้าและไฟล์

สร้าง PDF และ HTML จากต้นฉบับเดียวกัน ตรวจขอบเขตข้อความระหว่างสร้าง ไม่มีข้อความเกินขอบเขตที่กำหนด ผลจำนวนหน้าสุดท้ายอยู่ BUILD_REPORT.json ตรวจภาพ render ทุกหน้าเพื่อดูแนวขอบ การแสดงอักษร ภาพ และภาคผนวก

ตรวจด้วย tools/validate.py: จำนวนหน้าและสารบัญ บท 1–15 ภาพ HTML ทุกไฟล์ และเนื้อหา PDF streams ของภาคผนวกผู้แต่งให้ตรงต้นฉบับเดิม ไม่ได้อ้างว่าทดสอบสคริปต์กับทุกระบบปฏิบัติการหรือทุกฟอนต์

ต้นฉบับแก้ไขได้เป็น Markdown และ HTML ไม่ได้จัดทำ Word ในฉบับนี้

## ข้อจำกัดที่ต้องคงไว้

- ยังไม่มีการทดลองบนรถจริงหรือผล clone สำเร็จที่ตรวจซ้ำในงานนี้
- ภาพ Lexus และ FRM ไม่มีชุดฉลากกับ PCB สองด้านชัดครบ จึงไม่ใช้กำหนดขาปลั๊ก จุดโปรแกรม หรือความเข้ากันได้
- ภาพ GM เป็นตัวอย่างใน bulletin ต้องอ่านรุ่นปีและ VIN breakpoint จากเอกสารเต็ม ไม่ใช้ภาพยืนยันรถทุกรุ่น
- ภาพจากต้นทางภายนอกไม่มีใบอนุญาตแบบเปิดที่ตรวจยืนยัน สิทธิ์คงเป็นของเจ้าของภาพและระบุใน VISUAL_SOURCES.md
- ภาพวาดวงจรเป็นแผนที่หน้าที่/สัญญาณที่ย่อส่วน ไม่ใช่ schematic เต็มทุกอุปกรณ์ และไม่ใช่วงจรโรงงานของรถแต่ละรุ่น
- รายการเครื่องมืออิงเอกสารที่อ้าง ไม่รับรองเมนูปัจจุบันของเครื่องทุกเวอร์ชัน ต้องตรวจรายการตรงเครื่องก่อนทำงาน
- ประวัติและคำขอบคุณท้ายเล่มเป็นเอกสารเดิม ไม่ถือว่าบุคคลหรือ Claude ที่ถูกกล่าวถึงได้ตรวจหนังสือ BCM นี้แล้ว

Claude ต้องตรวจต่อและบันทึกข้อค้นพบ ไม่ให้เปลี่ยนข้อจำกัดที่ยังไม่ยืนยันเป็นคำรับรอง
