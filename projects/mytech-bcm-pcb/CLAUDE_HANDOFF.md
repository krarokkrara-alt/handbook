# ส่งต่องานหนังสือ BCM ให้ Claude

## ความต้องการผู้ใช้

ทำหนังสือ BCM ภาษาไทยเน้นวงจรบน PCB และโปรแกรมสำหรับทั้งย้ายชิปและย้ายข้อมูลไปกล่องทดแทน ครอบคลุมญี่ปุ่น ยุโรป อเมริกา ใช้ภาพจริงก่อน หากไม่มีให้วาดโดยอ้าง datasheet/หลักฐานบอร์ดจริง ใช้ประวัติผู้แต่งจากงานเดิม ปกต้องสวยมีหลายโมดูล พร้อม แจกฟรี และ แต่งโดย MyTech ผู้ใช้กำหนดให้รวมไว้ในโฟลเดอร์ใหม่ของ https://github.com/krarokkrara-alt/handbook พร้อม README ให้ Claude รับช่วง

Agent ช่วยรับผิดชอบคำสั่งที่ผู้ใช้ส่งมา ไม่ใช่ให้ผู้ใช้เลือกสี่โหมดตายตัว

## สถานะส่งมอบ

มีหนังสือ PDF ต้นฉบับ Markdown ฉบับ HTML ปก ภาพถ่าย 3 ภูมิภาค ภาพวาดหน้าที่ 5 ภาพ และภาคผนวกผู้แต่งเดิม 4 หน้า โครงที่ยึดคือ EDITORIAL_PLAN.md ผลสร้างล่าสุดอยู่ BUILD_REPORT.json ภาพจริงเป็นตัวอย่างศึกษาบอร์ด ไม่ใช่ชุดพิสูจน์ความเข้ากันได้ของกล่องหรือรายงานซ่อมของ MyTech

## อ่านตามลำดับ

1. README.md และ QA_REPORT.md

5. source-documents/Author_and_Acknowledgements.pdf — คงเดิมครบหน้า

## งานถัดไปที่ต้องทำ

ตรวจความถูกต้องของวงจรและคำอธิบายเครื่องมือกับเอกสารต้นทาง โดยเฉพาะ TCAN1042 รุ่น V/ไม่มี V, TJA1021 RXD open-drain, M95640-A125/A145 SO8 และความต่าง EEPROM ภายนอกกับ emulation ตรวจคำกล่าวอ้าง Autel/CGDI/MDflasher/Orange-5 ว่าไม่ขยาย read-write เป็น full clone

ตรวจตาราง/ย่อหน้ากรณีรถกับเอกสารและ revision ที่ระบุ รหัสชิปบนภาพไม่ชัดต้องคงสถานะไม่ยืนยัน อย่าแทนรูปด้วยภาพคนละฮาร์ดแวร์ ภาพ ACDP ที่พบในงานวิจัยเขียน XDT256 แม้หน้าเว็บยก XDT384 จึงยังไม่ได้ใช้ภาพนั้นในเล่ม

ตรวจสิทธิ์ภาพที่ใช้และเสนอทางเลือกภาพที่เจ้าของอนุญาตอย่างชัดเจน ภาพ GM เป็นของ GM ไม่ใช่ public domain เพียงเพราะเก็บบน NHTSA อย่าเปลี่ยนข้อความทะเบียนภาพว่าได้รับอนุญาตถ้าไม่มีหลักฐาน

พัฒนาเป็นกรณีหน้างานเพิ่มเมื่อมีชุดฉลาก ภาพ PCB สองด้าน รหัส MCU/EEPROM ขาปลั๊กยืนยัน และผลทดสอบจากชิ้นงานเดียวกัน ขณะนี้อย่าเติมจุดต่อเครื่องโปรแกรม ค่าแรงดันเขียน อุณหภูมิถอดชิป หรือไฟล์ dump จากการเดา

บันทึกผลตรวจเป็น CLAUDE_REVIEW.md แยกประเด็นที่แก้ได้ทันทีออกจากข้อมูลที่ต้องหาเพิ่มเติม หากแก้เนื้อหาให้สร้าง PDF/HTML ใหม่และตรวจภาพทุกหน้า ไม่อ้างว่าทดสอบบนรถจริงถ้าไม่มีผลทดสอบ ไม่มีคำสั่งให้เผยแพร่หรือ push การแก้รอบถัดไปโดยอัตโนมัติ

## วิธีสร้างและตรวจ

ทำงานจากโฟลเดอร์นี้ ใช้ `python tools/build_book.py` แล้ว `python tools/validate.py` ต้องมี reportlab Pillow pypdf และฟอนต์ไทย สคริปต์ offline เก็บต้นฉบับภาพใน assets ไม่ต้องเรียกเว็บระหว่าง build ผล QA ทางภาพต้องทำอีกครั้งหลังเปลี่ยนฟอนต์หรือเนื้อหา

## สิ่งที่คงไว้

ชื่อผู้แต่ง Supunya Pharaphong ในนาม MyTech ไม่ขยายประวัติ วุฒิหรือตำแหน่ง เอกสารท้ายเล่มเป็นต้นฉบับเดิม ข้อความขอบคุณ Claude ในภาคผนวกไม่ยืนยันว่า Claude ตรวจหนังสือ BCM แล้ว

## ผลการเริ่มตรวจอัตโนมัติ

วันที่ 17 พฤศจิกายน 2569 เรียก tools/claude_handoff.py แล้ว พบ Claude CLI แต่คำสั่งจบด้วย exit code 1 และข้อความ `Not logged in · Please run /login` จึงยังไม่มีผลตรวจหนังสือจาก Claude ไฟล์ CLAUDE_REVIEW.md ในรอบนี้เป็นข้อความขัดข้อง ไม่ใช่รายงานตรวจ เมื่อเจ้าของเครื่องลงชื่อเข้าใช้ Claude แล้ว ให้เรียกจากรากคลังอีกครั้ง:

```powershell
python tools/claude_handoff.py --task projects/mytech-bcm-pcb --instruction "Read CLAUDE_HANDOFF.md and review the BCM handbook; record findings without publishing changes"
```
