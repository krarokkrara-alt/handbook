## P1 ต้องแก้ก่อนส่งฉบับ 2

### 1 ย้ายเอกสารผู้แต่งสี่หน้าไปหลังปกทันที

พบ `writer.append(author)` หลัง body ทั้งหมด และ HTML ต่อภาพผู้แต่งท้ายเอกสาร จึงยังอยู่ท้ายเล่ม ต้องเปลี่ยนทั้ง PDF และ HTML ตามลำดับ: ปก > ผู้แต่งและกิตติกรรมประกาศเดิมสี่หน้าครบ > วิธีอ่าน > สารบัญ > เนื้อหา ห้ามเพิ่มหน้าคั่นก่อนเอกสารผู้แต่งจนไม่ใช่หลังปกทันที

ใส่ประโยคอธิบายบริบทกิตติกรรมประกาศในหน้าวิธีอ่านได้: “เอกสารประวัติและกิตติกรรมประกาศสี่หน้าคงจากต้นฉบับเดิม การกล่าวถึง ChatGPT, Claude หรือผู้สนับสนุนในเอกสารนั้นไม่ใช่หลักฐานว่าบุคคลหรือระบบดังกล่าวได้ตรวจหนังสือ BCM ฉบับนี้”

แก้เลขหน้า สารบัญ bookmarks และรายงานจำนวนหน้าจาก mapping เดียว ปัจจุบัน `page if page<3 else page+1`, `p+1` และ `p-1 if p<3 else p` เป็นค่าชดเชยเฉพาะโครงเดิม เมื่อแทรกผู้แต่งจะผิดได้ง่าย ตรวจโดยเปิด PDF แต่ละ bookmark เทียบหัวบทและเลขสารบัญจริง ไม่ตรวจเพียงจำนวนหน้า

### 2 แทน signal map อย่างน้อยบางภาพด้วย schematic ที่ใช้วิเคราะห์ได้

CAN/LIN/SPI ในตัวสร้างเป็นกล่องข้อความที่เส้นต่อเข้าขอบกล่องตามความสูง ไม่ได้ต่อขาจริงและไม่มีอุปกรณ์แวดล้อม คำบรรยายปัจจุบันยอมรับข้อจำกัดนี้ถูกต้อง แต่ไม่ตอบคำขอวงจรระดับบอร์ดได้เพียงพอ ฉบับ 2 ควรมีอย่างน้อยหนึ่ง schematic ต่อหัวข้อต่อไปนี้:

- CAN: แยก TCAN1042 รุ่นธรรมดาที่ขา 5 เป็น NC กับรุ่น V ที่ขา 5 เป็น VIO เขียนขา TXD/RXD/STB/VCC/GND/CANH/CANL ครบ ใส่ decoupling และ topology termination ตามวงจรตัวอย่างที่เลือก แสดงจุดวัด logic และ bus อย่างชัดเจน ไม่ใส่ termination สองตัวบนทุก BCM โดยอัตโนมัติ
- LIN: TJA1021 พร้อม VBAT, INH, RXD pull-up, SLP_N, TXD, GND, local wake และขาบัส ต้องแยก commander ซึ่งมีตัวต้านทานและไดโอดภายนอกจาก responder อย่าวาด INH เป็นไฟเลี้ยง logic 5 V ที่พร้อมใช้โดยตรง
- EEPROM: M95640 SO8 แสดงสาย SPI, VCC/VSS, decoupling และสถานะ W#/HOLD# ให้ชัด พร้อมระบุว่านี่คือวงจรทดสอบอุปกรณ์นอกบอร์ดหรือ application circuit ไม่ใช่สูตรหนีบคลิปใน BCM ทุกแบบ
- โหลด: เลือก IC high-side หนึ่งรุ่น เช่น TPS1H100-Q1 หรือ low-side จาก TIDA-00296 แล้ววาดวงจร application รวมโหลด ทางกลับกระแส และขา diagnosis หนึ่งวงจรที่มีแหล่งข้อมูลตรง ชี้การวัดแรงดันตกคร่อมสวิตช์ขณะมีโหลด ห้ามใช้เพียงภาพกล่อง Protection > Buck เป็นตัวแทน schematic ทั้งบท
- ภาคจ่ายไฟ: ใช้ schematic ย่อยที่ระบุรุ่นชิปจริงจาก reference design แยก VIN/EN/SW/FB/VOUT/GND และค่าชิ้นส่วนเฉพาะตัวอย่าง มีคำกำกับว่า reference board ไม่ใช่วงจร Toyota/BMW/Ford

หลักฐานปฐมภูมิที่ตรวจแล้ว: [TI TCAN1042-Q1 Rev D](https://www.ti.com/lit/ds/symlink/tcan1042-q1.pdf), [NXP TJA1021 Rev 9](https://www.nxp.com/docs/en/data-sheet/TJA1021.pdf), [ST M95640 DS8799 Rev 10](https://www.st.com/resource/en/datasheet/m95640-a125.pdf), [TI TIDA-00296 design files](https://www.ti.com/tool/TIDA-00296), [TI TIDA-00745 guide TIDUBN3](https://www.ti.com/lit/ug/tidubn3/tidubn3.pdf)

แต่ละภาพต้องระบุชื่อเอกสาร revision หน้า/รูปที่อ้าง และการเปลี่ยนจากต้นทาง เช่น วาดใหม่เฉพาะส่วน ใช้เส้นประตรงส่วนที่ไม่ได้ตรวจบนรถ ห้ามทำให้ผัง MCU↔transceiver ดูเป็นภาพตำแหน่งขาจริงด้วยการลากเส้นเข้ากล่องโดยไม่ชี้ขา

### 3 เพิ่มใบวิเคราะห์ดีเสียที่มีสภาวะและขอบเขตคำตัดสิน

ประโยคในบท 3 และ 6 มีลำดับคิดถูก แต่ยังให้ผู้อ่านสร้างเกณฑ์เอง ควรเพิ่มตารางที่มีคอลัมน์ “โหนด/สถานะทดสอบ/สิ่งคาดจากเอกสาร/สิ่งพบ/สิ่งที่ตัดออกได้/ตรวจถัดไป” อย่างน้อยกรณีต่อไปนี้:

- ไฟเข้า regulator มี แต่ไม่มีเอาต์พุต: ตรวจ enable และโหลดชอร์ตแยก ไม่ตัดสิน IC เสียจากค่าเดียว
- ไฟนิ่ง reset ถูกดึงเป็นช่วง: เทียบ supervisor/watchdog และการเริ่มระบบ ไม่ตัดสิน MCU เสียทันที
- CAN TXD เปลี่ยนแต่ bus ไม่เปลี่ยน: ตรวจ STB, VCC/VIO, บัสลัดและ termination ก่อนเปลี่ยน transceiver
- CAN bus เปลี่ยนแต่ RXD ไม่เปลี่ยน: ตรวจ mode และ receiver path; รูปคลื่น bus จากอีกโมดูลไม่ยืนยัน MCU ของกล่องนี้ทำงาน
- LIN ไม่มีคำตอบ: ต้องมี header ของ commander ที่เกี่ยวข้อง และตรวจว่ากล่องตื่นแล้วก่อนตัดสิน responder เสีย
- smart high-side output มีแรงดันแต่โหลดไม่ทำงาน: แยก diagnostic current/open-load กับการจ่ายกระแสจริง และตรวจข้ออนุญาตของการสั่งงาน
- อ่าน EEPROM สองครั้งได้เหมือนกัน: ผ่านความทำซ้ำของการอ่าน แต่ยังไม่ยืนยันอุปกรณ์/พื้นที่ถูกต้อง; FF/00 และขนาดตรงยังไม่พอ

ใช้คำว่า “สอดคล้องกับ” หรือ “ต้องตรวจต่อ” เมื่อหลักฐานยังแยกสาเหตุไม่ครบ ส่วน “เสีย” ต้องมีผลแยกชิ้นส่วน/ทางเดินหรือวิธีทดสอบของผู้ผลิตที่เพียงพอ แรงดัน logic ที่ระบุเป็นค่า nominal ให้แยกจาก VIH/VIL และ recommended operating range ไม่ใช้ absolute maximum เป็นค่าทดสอบ

### 4 เพิ่มขั้นตอนเครื่องมือที่ทำตามและตรวจผลได้หนึ่งกรณี

บท 14 ปัจจุบันเป็นตารางเปรียบเทียบชื่อเครื่องมือ ไม่ใช่ขั้นตอนใช้งาน ให้เลือกกรณีที่มีคู่มือผู้ผลิตจริง เช่น อ่าน EEPROM นอกบอร์ดด้วย XP400 Pro หรือ FRM กับ ACDP Module 08 แล้วแสดง: รุ่นเครื่อง/โปรแกรม/อะแดปเตอร์ > รหัสชิปและ package > การเตรียมไฟและการต่อจากคู่มือ > การตรวจ connection > Read > Save file > Read ซ้ำ > Compare/hash > สำรองกล่องทดแทน > Write เฉพาะเมื่อความเข้ากันได้ยืนยัน > Verify > ทดสอบระบบรถแยกต่างหาก

ชื่อเมนูต้องคงจากคู่มือหรือภาพหน้าจอที่ตรวจแล้ว ถ้าไม่มีภาพหน้าจอของเวอร์ชันนั้น ให้ทำเป็น “ลำดับปฏิบัติงานเรียบเรียงใหม่” ไม่วาดหน้าโปรแกรมเลียนแบบแล้วเรียกว่า screenshot จริง ข้อความ success ต้องระบุว่าคำสั่งใดผ่าน ไม่สรุป clone สำเร็จทั้งรถ

ข้อมูล primary: [Autel XP400 Pro User Manual](https://autel.com/u/cms/www/202205/09210038wyjo.pdf), [Yanhua ACDP Module08](https://www.acdpmaster.com/module/module8en.html) และภาพ connection ของแหล่งนี้ ภาพ m8_03.jpg เขียน MC9S12XDT256 แต่ข้อความตัวอย่างในหน้าเขียน MC9S12XDT384 จึงต้องแยกอย่างชัดเจน ห้ามใช้รูปแรกเป็นหลักฐานจุดต่อ XDT384

## P2 ความครบถ้วนและรูปแบบที่ต้องปรับ

### 5 ตารางควรเป็นตารางจริง

ตัวสร้าง PDF ใช้ `text(' | '.join(cells))` และ HTML ใช้ `<p>` สำหรับแถว Markdown ทำให้ข้อมูลเปรียบเทียบสูญเสียแนวคอลัมน์และอ่านข้ามหน้าได้ยาก ต้องสร้าง table จริงทั้งสองฉบับ กำหนดความกว้างคอลัมน์ที่อ่านภาษาไทยได้ หัวตารางซ้ำเมื่อขึ้นหน้าใหม่ และไม่แยกชื่ออุปกรณ์ออกจากเงื่อนไขที่เกี่ยวข้อง

### 6 ย้ายภาพใกล้เนื้อหาที่อธิบาย

ภาพจริงทั้งหมดอยู่ภาคท้าย ทำให้บทกรณีญี่ปุ่น/ยุโรป/อเมริกายังอ่านเป็น coverage list ให้ใส่ภาพที่ตรวจแล้วใกล้กรณีนั้น โดยกำกับว่าเป็นหลักฐานระดับรูปแบบบอร์ด ไม่ใช่หลักฐานอ่านเขียนสำเร็จ เพิ่มตัวชี้ตำแหน่งเฉพาะสิ่งที่อ่านได้จริง ห้ามพิมพ์เบอร์ MCU ที่เดาจากขนาดตัวถัง

ในเอกสาร GM Bulletin 21-NA-183 ภาพ 5883904 หน้า 4 ใช้สอนการตามต้นเหตุน้ำกับการตรวจ PCB ได้ แต่ไม่ใช่วงจรหรือวิธีซ่อม IC ของ GM ทุกรุ่น อ้างเอกสารตรง: https://static.nhtsa.gov/odi/tsbs/2022/MC-10213703-0001.pdf

### 7 สถานะภาพและลิขสิทธิ์ให้สัมพันธ์กับการเผยแพร่จริง

การระบุเจ้าของภาพไม่เท่ากับได้รับอนุญาตภาพ เงื่อนไข “หนังสือแจกฟรี” ไม่ใช่ใบอนุญาตทั่วไปของภาพต้นทาง ต้องคงสถานะสิทธิ์แยกไฟล์ ไม่ใช้ถ้อยคำว่า verified rights หากเพียงเห็นภาพบนเว็บ แยกภาพที่ลงหนังสือแล้ว ภาพที่เก็บค้นคว้า และภาพที่เพียงลิงก์ไว้ให้ชัด

### 8 แหล่งอ้างอิงต้องตามระดับข้อความ

TCAN1042-Q1 Rev D, TJA1021 Rev 9, M95640 DS8799 Rev 10 ตรวจได้จากหน้าเอกสารผู้ผลิต ตัวเลขและตารางสถานะใน v2 ต้องมี page/section ตรง ไม่ใช้ลิงก์ product family เพียงลิงก์เดียวรองรับค่าทุกตัว เอกสาร TI TIDA-00745 มีค่าบางตำแหน่งสรุปไม่เหมือนกัน จึงต้องระบุว่าค่าทดสอบยกจากตาราง/รูปใด ไม่รวมทุกค่าเป็น specification เดียวโดยไม่ตรวจ

## เกณฑ์ตรวจรอบ 2

1. เอกสารผู้แต่งเดิมสี่หน้าอยู่ PDF หน้า 2–5 และ HTML หลังปกก่อนวิธีอ่านจริง ภาพ/QR ไม่หาย
2. มี schematic application พร้อมอุปกรณ์แวดล้อมและ revision อ้างอิงอย่างน้อย CAN, LIN, EEPROM และภาคกำลังหนึ่งวงจร
3. มีการแยก NC/VIO, INH/logic rail, EEPROM main array/identification page และค่า nominal/logic threshold อย่างถูกต้อง
4. มีใบวิเคราะห์ดีเสียอย่างน้อยสี่กรณีที่บอกสภาวะและไม่สรุปเกินหลักฐาน
5. มีขั้นตอนเครื่องมือที่ระบุเมนูจาก primary source หรือป้ายว่าเป็น workflow เรียบเรียง ไม่ปลอมเป็นผลทดสอบจริง
6. ตาราง PDF/HTML อ่านได้จริง ไม่มีเส้นข้อความไหลเป็นย่อหน้าเดียว
7. สารบัญ bookmarks เลขหน้า และลิงก์ภาพถูกหลังการย้ายผู้แต่ง เปิดดู PDF ไม่ใช้ bounds check อย่างเดียว
8. README และ handoff อธิบายสถานะฉบับจริง ไม่อ้างผู้เชี่ยวชาญหรือ Claude ตรวจแล้วจากกิตติกรรมประกาศเก่า

รายงานนี้ยังไม่ใช่ผลตรวจ v2 ซึ่งยังไม่ได้รับไฟล์สำหรับตรวจซ้ำ
