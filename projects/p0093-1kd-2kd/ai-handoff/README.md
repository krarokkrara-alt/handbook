# เริ่มงานต่อด้วย AI หนังสือ P0093 Toyota 1KD และ 2KD

โฟลเดอร์นี้เป็นจุดเริ่มสำหรับสั่ง AI ทำหนังสือต่อ ใช้ต้นฉบับชุดเดียวในโครงการแม่ ไม่สร้างสำเนาหนังสือหลายชุดที่แก้แล้วไม่ตรงกัน

## หนังสือเล่มนี้ใช้หลักการอะไร

หนังสืออธิบายเฉพาะ P0093 ใน Toyota 1KD-FTV และ 2KD-FTV โดยเริ่มจากการทำงานของระบบ แล้วใช้หลักฐานแยกสาเหตุ ก่อนเลือกวิธีแก้และตรวจยืนยันหลังซ่อม

1. **มองเป็นระบบป้อนกลับ:** เชื่อมคำสั่ง ECU การขับ SCV การเคลื่อนของวาล์ว ปริมาณน้ำมันเข้าปั๊ม แรงดันราง และสัญญาณเซ็นเซอร์ แยกคำสั่ง ผลวัด และผลทางกล/ไฮดรอลิกออกจากกัน
2. **อ่านทางน้ำมันครบวงจร:** ด้านดูดและป้อน ปั๊ม ราง หัวฉีด และทางกลับ รวมถึงความแตกต่างของ limiter กับวาล์วระบายที่ควบคุมด้วยไฟฟ้า ไม่สรุปว่า P0093 ต้องมีน้ำมันรั่วภายนอก
3. **วินิจฉัยแบบพิสูจน์สมมติฐาน:** ทุกสาเหตุต้องมีหลักฐานสนับสนุน วิธีแยกจากสาเหตุอื่น ผลที่อาจพบ วิธีแก้เมื่อยืนยันแล้ว และวิธียืนยันหลังซ่อม ไม่ใช้รายการเปลี่ยนอะไหล่ตามโค้ด
4. **ใช้ข้อมูลตรงรุ่น:** แยกเครื่องยนต์ ตลาด รุ่นเอกสาร และชุดอุปกรณ์ ค่าแรงดัน เลขขา เงื่อนไข DTC และการทดสอบต้องมีหลักฐานตรงขอบเขต ห้ามเดาหรือรวมสเปกต่างเอกสารเป็นค่ากลาง
5. **ภาพช่วยอธิบาย:** ใช้วงจร SVG ที่วาดใหม่พร้อมจุดวัด ทิศทางและคำอธิบาย แยกภาพหลักการจากผังต่อสายเฉพาะเอกสาร ภาพกราฟสังเคราะห์ไม่ใช่ผลวัดจริง
6. **เรียนจากพื้นฐานไปสู่ขั้นสูง:** มีบทเรียนวงจร กิ่งวิธีแก้ กรณีจำลองพร้อมเฉลย และแบบบันทึกผลวัด ฉบับคอร์สย่อคัดภาพสำคัญและไฮไลต์บางจุด ไม่ไฮไลต์ทุกย่อหน้า

## ข้อห้ามและขอบเขต

- ห้ามคลายท่อ common rail ขณะเครื่องทำงาน ปิดระบบป้องกัน อุดทางระบาย หรือใช้วิธีลดแรงดันตกค้างที่เดาขึ้นเอง
- ห้ามเหมารวม SCV แบบ NO/NC เรื่องทิศ duty/current หรือพฤติกรรมเมื่อถอดปลั๊ก
- ห้ามถือ PID กับสัญญาณจากเซ็นเซอร์ตัวเดียวกันเป็นหลักฐานวัดแรงดันอิสระสองชุด
- ห้ามนำตัวอย่าง DR201E Hilux TASA Argentina หรือเอกสาร RM1151E เฉพาะ 1KD ไปใช้แทนรถไทยทุกปีหรือ 2KD โดยไม่ยืนยัน application
- ห้ามแต่งประสบการณ์ซ่อมจริง กรณี A–H เป็นกรณีจำลอง ภาพวาดไม่ใช่ภาพถ่ายชิ้นส่วนจริง
- ห้ามเผยแพร่ PDF คู่มือ OEM ที่ดาวน์โหลดเพื่อวิจัย ภาพจากเว็บไซต์ต้องตรวจสิทธิ์ การใส่อ้างอิงใต้ภาพอย่างเดียวไม่ใช่ใบอนุญาตเผยแพร่
- อย่าเปลี่ยนหนังสือ ECU เดิมหรือไฟล์ synced sources ระหว่างทำงานเล่มนี้

## งานค้างจริงที่ควรทำก่อนขยายเล่ม

ณ ชุดส่งมอบวันที่ 21 ตุลาคม 2569 การเปิดดูภาพของ PDF เล่มเต็มฉบับสุดท้ายเสร็จ 28/71 หน้า ได้แก่ 26–30 และ 49–71 ยังเหลือหน้า 1–25 และ 31–48 ส่วนคอร์สฉบับสุดท้ายยังไม่ได้เปิดดูภาพครบ แม้ต้นแบบก่อนเปลี่ยน footer มีผลตรวจครบ 15 หน้าแล้ว ห้ามยกผลคนละ hash มาอ้างว่าได้ตรวจไฟล์ใหม่ครบ

Word ตรวจโครงสร้างและภาพฝังผ่าน แต่ยังไม่มีผลตรวจการจัดหน้าทุกหน้า เครื่องมือแปลงมาตรฐานไม่มี LibreOffice และ Word ส่งออก PDF ค้างในการทดสอบก่อนหน้า จึงต้องหาวิธีตรวจที่สำเร็จจริงหรือคงป้ายว่าเป็นต้นฉบับแก้ไขได้

ยังไม่มี VIN ของรถผู้ใช้และภาพถ่ายอุปกรณ์ที่ผ่านทั้งสิทธิ์ฝังและความตรงรุ่น ให้ระบุช่องว่างไว้ ไม่เติมค่าหรือภาพเหมือนจริงเพื่อกลบช่องว่าง

## วิธีแก้ต้นฉบับโดยไม่ทำข้อมูลหาย

แก้บทต้นทางใน `manuscript/` และหลักฐานใน `research/` ก่อน แล้วรวมด้วย `tools/assemble_master.py` อย่าแก้เฉพาะ MASTER_DRAFT เพราะจะถูกเขียนทับเมื่อรวมใหม่ ดูสคริปต์ผลิตไฟล์ใน `tools/` ซึ่งใช้ runtime และ Chrome ตามสภาพแวดล้อมเดิม ต้องปรับตำแหน่งเครื่องมือเมื่อย้ายเครื่อง

ทุกครั้งที่เปลี่ยน PDF ให้บันทึก SHA256 ใหม่ ตรวจสารบัญ เลขหน้า bookmarks และเปิดดูหน้าที่เปลี่ยนพร้อมหน้าไหลต่อ ก่อนอ้างว่าผ่าน ตรวจทุกหน้าของฉบับส่งมอบเมื่อปิดเล่ม และอัปเดต README สถานะตรวจ และ manifest ให้ตรงไฟล์จริง

## ข้อความพร้อมคัดลอกไปสั่ง AI

```text
ทำงานต่อใน repository handbook ที่ projects/p0093-1kd-2kd
อ่าน ai-handoff/README.md, AGENTS.md, STATUS.md และ delivery/QA_STATUS.md ก่อน
หนังสือใช้วงจรการทำงานและหลักฐานแยกสาเหตุ P0093 Toyota 1KD/2KD
เริ่มจากปิดงานตรวจภาพ PDF ที่ค้าง ตรวจฉบับจริงโดยเทียบ SHA256 และรายงานหน้าที่เปิดดูจริง
ใช้ทีมวิจัย OEM/DENSO ผู้วิเคราะห์วงจร และบรรณาธิการวินิจฉัย แบ่งเจ้าของไฟล์ชัดเจน
ห้ามเดาค่า pinout เงื่อนไข DTC หรือวิธีซ่อม และอย่าเหมารวมสเปกต่างรุ่น
ทุกกิ่งต้องมีวิธีแยกสาเหตุ ผลคาดหมายแบบมีเงื่อนไข วิธีแก้เมื่อพิสูจน์แล้ว และยืนยันหลังซ่อม
คงข้อกำหนดแรงดันสูง แยกกรณีจำลองจากจริง และตรวจสิทธิ์ภาพก่อนเผยแพร่
แก้บทต้นทางแล้วรวมเล่มใหม่ บันทึกสิ่งที่เปลี่ยน หลักฐาน ช่องว่าง และงานถัดไปใน STATUS.md
คำสั่งนี้อนุญาตให้ทำงานต่อรอบใหม่ กำหนดเวลา 07:00 ของงานเดิมเป็นประวัติ ไม่ใช่ตารางงานใหม่
ก่อนส่งมอบให้ตรวจตามจริง ไม่กล่าวว่าสมบูรณ์หากยังมีหน้าหรือข้ออ้างที่ไม่ได้ตรวจ
```
