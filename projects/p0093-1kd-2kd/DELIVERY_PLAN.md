# แผนชุดส่งมอบ P0093

สถานะ 21 ตุลาคม 2569 เวลา 04:34 น. ไทย ยังไม่ใช่รายการไฟล์ฉบับสุดท้ายที่อนุมัติแล้ว

## ผลงานหลัก

1. หนังสือ PDF เล่มเต็ม มีวงจร 16 แผ่น บทเรียน 8 ตอน ตารางวิธีแก้ 15 กิ่ง กรณีจำลอง 8 กรณี และแบบบันทึก 6 แบบ
2. PDF ฉบับย่อสำหรับคอร์ส มีแนวทางเรียน 2 หน้า วงจรหลัก 6 แผ่น แบบบันทึก 6 แบบ และหน้าอ้างอิง 1 หน้า ไฮไลต์เฉพาะ 3 จุดสำคัญ
3. ต้นฉบับ Word สำหรับแก้ไข พร้อมภาพและเขตข้อมูลสารบัญ ระบุสถานะว่าไม่ได้รับรองการจัดหน้าทุกหน้า
4. ต้นฉบับ Markdown วงจร SVG/PNG และทะเบียนอ้างอิงที่แก้ไขต่อได้
5. README ภาษาไทย รายการข้อจำกัด และ manifest พร้อม SHA256 ของไฟล์ส่งมอบจริง

## เงื่อนไขปิดงาน

- Freeze PDF แล้วบันทึก hash ก่อนแบ่งทีมตรวจทุกหน้าของฉบับนั้น
- ตรวจสารบัญ เลขหน้า bookmark และลิงก์แหล่งอ้างอิงหลังเปลี่ยนฉบับ
- หากแก้หน้าที่พบปัญหา ต้องเปิดตรวจหน้าที่เปลี่ยนและหน้าไหลต่ออีกครั้ง
- ห้ามเรียกกรณีจำลองว่ารถลูกค้าจริง ห้ามเรียกภาพวาดว่าภาพถ่ายจริง
- ระบุข้อจำกัด VIN รุ่นปี ตลาด เลขอุปกรณ์ และตัวเลขที่ยังไม่มีหลักฐานตรงรุ่น
- หยุดเพิ่มเนื้อหาและไม่เริ่มรอบวิจัยใหม่หลัง 07:00 น.

## ขอบเขตไฟล์สำหรับ repository และ ZIP

รวมเฉพาะข้อความต้นฉบับและข้อมูล JSON ของโครงการนี้ วงจรที่ผู้จัดทำวาด SVG/PNG สคริปต์ผลิตไฟล์ README สถานะและบทบาททีม รวม PDF สำหรับผู้อ่านและต้นฉบับ Word ที่ผ่านการตรวจตามสถานะที่แจ้งไว้

ไม่รวม PDF คู่มือ OEM/DENSO ที่ดาวน์โหลดมาวิจัย ภาพ screenshot จากคู่มือ ภาพ QA รายหน้า ไฟล์ชั่วคราว logs ของโปรแกรม และ HTML ตรวจอ่านที่ฝัง absolute path ในเครื่อง ไฟล์ต้นฉบับ SVG ต้องคงคำอธิบายขอบเขตและแหล่งอ้างอิงไว้

ชุดส่งมอบต้องอยู่ในโครงการ P0093 นี้และไม่เปลี่ยนไฟล์หนังสือ ECU เดิมหรือ synced sources หากเผยแพร่ขึ้น GitHub ให้ stage เฉพาะโครงการนี้และตรวจรายการ staged ทุกไฟล์ก่อน commit/push

## ช่องว่างที่ต้องแจ้ง

ยังไม่มี VIN ของรถผู้ใช้ จึงไม่รับรองว่าค่าจาก DR201E Hilux TASA Argentina หรือ RM1151E 1KD ใช้กับรถตลาดไทยทุกคัน ภาพอุปกรณ์จริงยังไม่มีชุดที่ผ่านทั้งสิทธิ์ฝังและ application ส่วน DOCX เป็นไฟล์ต้นฉบับแก้ไขได้ที่ยังไม่มี visual approval การไม่มีรหัสซ้ำในสภาวะที่ทดสอบต้องไม่ถูกเขียนว่าแก้หายทุกโหลด
