# คอร์ส P0093 สำหรับ Toyota 1KD / 2KD

## ส่วนที่ 1 — เรียนวงจรเพื่อเลือกการตรวจให้ถูกคำถาม

เอกสารคอร์สนี้ใช้ฝึกวิเคราะห์ P0093 โดยเชื่อมทางเดินน้ำมัน วงจรไฟฟ้า และข้อมูลเครื่องสแกน ชื่อเครื่องยนต์ 1KD หรือ 2KD อย่างเดียวไม่ยืนยันว่ารถใช้ปั๊ม SCV ราง เซนเซอร์ หรือซอฟต์แวร์ชุดเดียวกัน ก่อนนำวิธีตรวจไปใช้กับรถจริง ต้องยืนยันรถและอุปกรณ์ พร้อมคู่มือที่ตรงกัน ตัวอย่างขั้วในเอกสารเฉพาะไม่ใช่ขั้วสากลของเครื่องยนต์ทั้งหมด

เมื่อเรียนจบ ผู้เรียนควรอธิบายได้ว่าแรงดันรางที่เห็นเป็นผลของอะไร เครื่องมือแต่ละชนิดวัดสิ่งใด และหลักฐานที่มีเพียงพอเลือกวิธีแก้หรือยัง เป้าหมายไม่ได้อยู่ที่จำชื่ออะไหล่ยอดนิยม แต่คือการเสนอสมมติฐานที่แข่งกัน เลือกการทดสอบแยกสาเหตุ และยืนยันผลซ่อมในขอบเขตที่ทำจริง

### เส้นทางเรียนจากภาพหกแผ่น

**ภาพ 01 — ตามน้ำมันไปและกลับ:** เริ่มจากถัง กรอง ทางป้อน ปั๊ม ราง และหัวฉีด แล้วแยกทางกลับออกจากทางแรงดันสูง ให้ผู้เรียนชี้ว่าถ้าส่งเข้าไม่พอหรือมีการสูญเสียภายใน แรงดันอาจตามความต้องการไม่ทันได้อย่างไร การไม่มีคราบเปียกภายนอกยังไม่ตัดปัญหาทางน้ำมันทั้งหมด และทางกลับที่มีน้ำมันไหลไม่ได้หมายถึงเสียเสมอ ต้องตรวจปริมาณด้วยวิธีและเงื่อนไขที่ตรงระบบ

**ภาพ 02 — อ่านวงควบคุม:** ชี้เส้นแรงดันเป้าหมาย ค่าที่เซนเซอร์รายงาน และการปรับคำสั่งไปยังระบบป้อนน้ำมัน เส้นเป้าหมายกับค่าจริงที่แยกกันเป็นจุดตั้งคำถาม ไม่ใช่คำพิพากษาว่าปั๊มเสีย ถามต่อว่าเชื้อเพลิงเข้าพอหรือไม่ ออกหรือระบายผิดปกติหรือไม่ และข้อมูลป้อนกลับเชื่อถือได้หรือยัง

**ภาพ 03 — แยกไฟอ้างอิง สัญญาณ และทางกลับเซนเซอร์:** ให้ผู้เรียนระบุจุดอ้างอิงทุกครั้งที่พูดว่า “วัดแรงดันไฟได้” ภาพนี้อธิบายหน้าที่ ไม่ยืนยันจำนวนสายหรือหมายเลขขาของรถทุกคัน การวัดเทียบตัวถังอย่างเดียวอาจไม่ตอบคำถามเดียวกับการวัดเทียบ sensor return ต้องเปิดผังที่ตรงรถก่อนต่อเครื่องมือ ไม่ทำสายบายพาสลงตัวถังเพื่อให้กราฟดูนิ่ง

**ภาพ 04 — แยกคำสั่งจากกระแสจริง:** ผู้เรียนต้องบอกให้ได้ว่าค่าในสแกนเนอร์เป็นคำสั่งหรือผลวัด การมีแรงดันสวิตช์ไม่รับรองว่ากระแสไหลครบ และการมีกระแสไม่รับรองว่าวาล์วเคลื่อนหรือปั๊มส่งน้ำมันถูกต้อง การวัดคร่อมวงขับต้องใช้เครื่องมือพิกัดและวิธีต่อที่เหมาะ ห้ามเดาว่าขาลบของโหลดเท่ากับกราวด์ตัวถัง

**ภาพ 05 — ตรวจชนิด SCV ก่อนตีความ:** DENSO มี SCV ที่สภาพไม่จ่ายไฟต่างกันตาม application จึงไม่ใช้การถอดปลั๊กแล้วดูว่าแรงดันขึ้นหรือลงเป็นวิธีทดสอบสากล และไม่ย้ายทิศ duty หรือกระแสจากรถอีกคันมาใช้โดยไม่ยืนยันเลขอุปกรณ์และนิยามข้อมูล

**ภาพ 16 — เปลี่ยนข้อสงสัยเป็นแผนตรวจ:** ก่อนต่อเครื่องมือ ให้เขียนว่าต้องการแยกสมมติฐานใดจากสมมติฐานใด ผลแบบไหนจะนำไปคนละกิ่ง และเมื่อใดต้องหยุดหรือส่งผู้เชี่ยวชาญ จากนั้นเลือกวิธีแก้เฉพาะส่วนที่พิสูจน์แล้ว พร้อมวิธีตรวจยืนยัน ไม่เริ่มจากรายการอะไหล่ที่จะเปลี่ยน

### จุดไฮไลต์สำหรับผู้เรียน

**ไฮไลต์ 1: P0093 เป็นผลตรวจจับ ไม่ใช่ชื่อชิ้นส่วนเสีย** ต้องรักษาข้อมูลก่อนลบรหัส และพิจารณารหัสร่วม หากมีข้อมูลแรงดันสูงก่อนตกหรือรหัสควบคุมแรงดันร่วม อย่าดูเฉพาะช่วงแรงดันต่ำท้ายเหตุการณ์

**ไฮไลต์ 2: คำสั่ง → กระแส → กลไก → ผลน้ำมัน เป็นคนละชั้น** ผลผ่านชั้นหนึ่งไม่รับรองอีกชั้น ค่าชดเชยกระบอกสูบไม่ใช่ปริมาตรน้ำมันไหลกลับ และระดับ return ใกล้กันไม่รับรองว่าปริมาณรวมผ่านเกณฑ์

**ไฮไลต์ 3: แก้แล้วต้องยืนยันสภาวะเดิมอย่างปลอดภัย** เดินเบาเรียบหลังซ่อมยังไม่รับรองอาการเมื่อร้อนหรือบรรทุก แยกคำว่า “ยังไม่เกิดซ้ำในการทดสอบนี้” จาก “พิสูจน์สาเหตุและแก้แล้ว” เสมอ

ห้ามใช้มือคลำจุดรั่วแรงดันสูง คลายท่อ common rail ขณะเครื่องทำงาน จ่ายไฟตรงเข้าหัวฉีดหรือ SCV หรืออุดทางระบายเพื่อกลบอาการ ก่อนเปิดระบบต้องลดและยืนยันแรงดันตกค้างตามคู่มือ หากมีรั่วอันตรายหรือเสี่ยงดับขณะขับ ให้หยุดทดสอบโหลดและส่งต่อในขอบเขตที่เหมาะสม

## ส่วนที่ 2 — กิจกรรมวิเคราะห์จากหลักฐานและรายงานผล

กิจกรรมเลือกจากกรณี A–H **ทั้งสองเป็นสถานการณ์จำลอง ไม่ใช่ผลทดลองรถจริง** ไม่มีค่าที่สมมติเป็นสเปกโรงงาน ผู้เรียนแยกสิ่งที่ทราบจากสิ่งที่ยังไม่ยืนยัน โดยใช้บทเต็มและแหล่งข้อมูลประกอบ

### กิจกรรม A — หลังเปลี่ยนกรอง พอขึ้นเนินจึงเกิดอาการ

รถเครื่อง 2KD เดินเบาเรียบหลังงานกรอง แต่วันถัดมาเกิด P0093 ขณะขึ้นเนินและบรรทุก ยังไม่มีเลขกรองหรือผลตรวจทางป้อน ผู้เรียนแยกข้อบกพร่องการประกอบออกจากปั๊มไม่พอหรือการสูญเสียด้านกลับที่ยังไม่ตรวจ

ใช้แบบ01ยืนยันรถ อุปกรณ์ และแหล่งวิธีตรวจ แบบ02เก็บรหัสร่วม freeze frame และเหตุการณ์ แยกคำบอก “ก่อนหน้านี้ไม่เป็น” จากผลทดสอบจริง ใช้แบบ04เลือกการตรวจพร้อมผลสองแบบที่ทำให้ไปคนละกิ่ง ยังไม่เปลี่ยนปั๊มหรือ SCV จากประวัติอย่างเดียว

บัตรข้อมูลเพิ่ม: พบซีลชุดกรองประกอบผิด ผลตรวจทางป้อนตามวิธีรถไม่ผ่าน หลังแก้จุดนั้นผ่าน แต่ยังไม่ได้ทำโหลดเดิม ให้ตอบว่ายืนยันอะไรและยังขาดอะไร ใช้แบบ03บันทึกผลกับเกณฑ์อ้างอิง แบบ05เทียบก่อน–หลัง และแบบ06รายงานขอบเขต ทดสอบหลังพักหรือโหลดใกล้เดิมอย่างปลอดภัยก่อนสรุป

### กิจกรรม G — แรงดันกระโดดพร้อมสัญญาณอื่น

PID แรงดันกระโดดพร้อมสัญญาณเซนเซอร์อีกตัว ยังไม่ทราบว่าใช้วงจรร่วมจริงหรือไม่ ให้แยกปัญหาข้อมูล/วงจรร่วมจากทางน้ำมัน ขอ EWD จุดอ้างอิง วิธีวัด และความละเอียดเวลา log ก่อนสรุป

ใช้ภาพ03/04แยกคำสั่ง ข้อมูลรายงาน และผลวัดจริง PIDกับสัญญาณเซนเซอร์ตัวเดียวไม่ใช่หลักฐานแรงดันน้ำมันอิสระสองระบบ ตรวจไฟอ้างอิง/ทางกลับตามผัง ไม่เปลี่ยนเซนเซอร์หรือ ECM ทันที และไม่บายพาสลงตัวถัง

บัตรข้อมูลเพิ่ม: พบวงจรร่วมผิดจากผลวัดขณะทำงาน ให้ระบุจุดเสียที่ยังต้องพิสูจน์ วิธีแก้ตามหลักฐาน และการตรวจ feedback/ควบคุมแรงดันหลังแก้ ใช้แบบ01–06เหมือนกิจกรรมA ไม่เติมค่าที่โจทย์ไม่ได้ให้

### เกณฑ์ประเมิน: ผ่าน / ยังไม่พอ

| ประเด็น | ผ่านเมื่อ | ยังไม่พอเมื่อ |
|---|---|---|
| รถและแหล่งข้อมูล | ยืนยันรถและเกณฑ์ตรงอุปกรณ์ | ใช้ชื่อเครื่องแทนข้อมูลรุ่น |
| การทดสอบ | มีสองสมมติฐานและผลที่แยกกิ่ง | ทายอะไหล่โดยไม่มีวิธีแยก |
| หลักฐาน | แยกคำสั่ง ผลวัด ข้อสันนิษฐาน | เดาค่าหรือถือPIDยืนยันแรงดันอิสระ |
| วิธีแก้ | ตามจุดที่พิสูจน์ รู้จุดหยุด/ส่งต่อ | เปลี่ยนสุ่ม อุด บายพาส วัดผิดพิกัด |
| ยืนยันผล | ใกล้สภาพเดิม รายงานข้อจำกัด | ไม่มีรหัสหลังลบเท่ากับหาย |

ถ้าไม่มีวิธีหรือเกณฑ์ตรงรถ ให้ระบุข้อมูลที่ขาดและแผนส่งต่อ ไม่เติมตัวเลข ผู้เรียนแก้แผนตามหลักฐานใหม่ได้ ผู้สอนประเมินเหตุผลและความปลอดภัยร่วมกัน

อ้างทะเบียนท้ายชุด: Toyota [T01,T05] เรื่องรหัส; DENSO [D06,D01] เรื่องSCV/ความปลอดภัย และ [D07] เรื่องcoding/learning กิจกรรมเป็นวิธีสอนของผู้เขียน ไม่ใช่ผังโรงงานทุกข้อ
