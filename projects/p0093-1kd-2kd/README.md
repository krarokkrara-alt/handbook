# หนังสือเจาะลึก P0093 Toyota 1KD และ 2KD

โครงการหนังสือเฉพาะโค้ด P0093 สำหรับเครื่องยนต์ 1KD-FTV และ 2KD-FTV เน้นวงจรการทำงานอย่างละเอียด การแยกสาเหตุด้วยหลักฐาน วิธีแก้ตามสาเหตุ และการทดสอบหลังซ่อม

## ขอบเขตที่ต้องยืนยันกับรถก่อนใช้งาน

เอกสาร DR201E ที่ใช้บางส่วนเป็น Hilux TASA สำหรับ Argentina และ RM1151E บางส่วนระบุเฉพาะ 1KD จึงไม่ย้ายเลขขาหรือค่าตรวจไปใช้กับ 2KD หรือตลาดไทยโดยอัตโนมัติ ต้องตรวจ VIN เดือนผลิต ตลาด หมายเลขอุปกรณ์ และเอกสารซ่อมให้ตรงก่อน ค่าแรงดัน การทดสอบ return และ SCV ไม่มีเกณฑ์เดียวที่ใช้แทนทุกชุดระบบ

P0093 ไม่ยืนยันว่ามีรั่วภายนอกเสมอไป เนื้อหาให้แยกหลักฐานทางป้อน ทางกลับ การควบคุม และความน่าเชื่อถือของสัญญาณก่อนเลือกซ่อม ห้ามคลายท่อ common rail ขณะเครื่องทำงาน หรือปิดการป้องกันเพื่อทดสอบ

## ทีมเอเจนต์

1. นักวิจัยคู่มือ Toyota และ DENSO แยกรุ่น ปี ตลาด และรุ่นเอกสาร
2. บรรณาธิการวงจรระบบเชื้อเพลิงและไฟฟ้ารถยนต์
3. บรรณาธิการวินิจฉัยและวิธีแก้ปัญหา
4. บรรณาธิการใหญ่รวมเล่มและตรวจหลักฐาน

เอเจนต์รับบทงานบรรณาธิการ ไม่ใช่การรับรองจากผู้เชี่ยวชาญมนุษย์

## แนวทางเนื้อหา

- กลไกการตรวจ P0093 และการอ่านหลักฐานก่อนตัดสินใจเปลี่ยนอะไหล่
- ทางเดินเชื้อเพลิง ความดัน ทางกลับ และวงจรควบคุมแบบป้อนกลับ
- ปั๊ม SCV เซนเซอร์แรงดันราง หัวฉีด และ ECU ตามชนิดระบบ
- ผังตรวจแยกสาเหตุและวิธีแก้ พร้อมผลตรวจที่ต้องได้ก่อน/หลังซ่อม
- เงื่อนไขที่ต่างกันระหว่าง 1KD กับ 2KD และคู่มือแต่ละฉบับ
- เคสฝึกที่ระบุว่าเป็นตัวอย่างจำลอง และแบบบันทึกผลวัด
