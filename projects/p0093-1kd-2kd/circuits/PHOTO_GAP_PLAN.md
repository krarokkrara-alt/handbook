# แผนช่องว่างภาพอุปกรณ์จริง — หนังสือ P0093 / 1KD / 2KD

ตรวจแหล่งวันที่ 21 ตุลาคม 2026 • งานรอบนี้เป็นแผนและการตรวจแหล่งเท่านั้น • ไม่ดาวน์โหลด ไม่ฝังภาพใหม่ ไม่แก้ภาพวงจร 16 แผ่นหรือ PDF

## ผลที่ใช้ตัดสินก่อน final

พบหน้าผู้ผลิต DENSO ที่มีภาพนำเสนอ **SCV, HP3 และหัวฉีด solenoid** สำหรับใช้เป็นลิงก์ดูรูปร่างประกอบ แต่ **ยังไม่มีภาพถ่ายจากเว็บที่ผ่านสิทธิ์สำหรับฝังลงหนังสือชุดนี้** เงื่อนไข DENSO ระบุว่าการใช้ภาพกราฟิกต้องได้รับความยินยอมเป็นลายลักษณ์อักษร การใส่เครดิตอย่างเดียวจึงไม่เปลี่ยนสถานะเป็นใช้พิมพ์ได้

ช่องว่างสำคัญคือภาพชิ้นส่วน **ตรงคัน/ตรง part number** โดยเฉพาะ rail variant และ rail sensor ควรได้ภาพถ่ายเองหรือภาพที่มีขอบเขตอนุญาตชัดเจนก่อนอ้างว่าเป็นของ 1KD/2KD รุ่นใด หน้า catalog ที่แสดงชิ้นส่วนทั่วไปยังไม่พิสูจน์ application ของภาพนั้น

คำว่า “ภาพนำเสนอผลิตภัณฑ์” ด้านล่างหมายถึงพบรายการภาพในหน้าผู้ผลิตพร้อมคำระบุชิ้นส่วน **ยังไม่รับรองจากการตรวจต้นฉบับภาพว่าเป็นภาพถ่ายจริงหรือภาพ render** และยังไม่รับรองหมายเลขชิ้นส่วนบนรูป ต้องตรวจภาพเต็ม/ข้อมูลเจ้าของสิทธิ์ในรอบจัดหาภาพก่อนพิมพ์คำว่า “ภาพถ่ายจริง”

## รายการชิ้นส่วนที่ต้องการ 5 รายการ

| รายการ | แหล่งที่ตรวจและสิ่งที่พบ | การใช้ตอนนี้ / สิทธิ์ | ข้อจำกัด application | ภาพที่ควรจัดหาเพื่อใช้จริง |
|---|---|---|---|---|

| **PH02 — ปั๊ม HP3** | [DENSO Common Rail Pump](https://www.denso-am.eu/products/diesel-components/common-rail-pump) หัวข้อ HP3 มีภาพชื่อ `HP3 type pump` แยกจาก HP2/HP4 | ลิงก์ดูชิ้นส่วนตระกูล HP3 ได้ในฐานะแหล่งอ้างอิง; ไม่ฝังภาพจากหน้านี้โดยถือว่ามีเครดิตแล้วเพียงพอ | ชื่อ HP3 ไม่ใช่หมายเลขปั๊มสำหรับรถทุกคัน และภาพหน้าเปิดอาจเป็นภาพ general product คนละรายการกับหัวข้อ HP3 จึงต้องเลือกภาพ/label ให้ตรง | ถ่ายปั๊ม 3 มุมให้เห็นทางเข้าด้านต่ำ ทางออกแรงดันสูง SCV และป้ายจริง แสดงทิศตามรอยต่อที่ยืนยันกับเอกสาร ไม่เดาจากรูป เชื่อมรูป 01/10/14 |
| **PH03 — หัวฉีด solenoid** | [DENSO Common Rail Injector](https://www.denso-am.eu/products/diesel-components/common-rail-injector) หัวข้อ `Solenoid-type injector` มีรายการภาพชื่อนี้ และมีภาพรวมหลายหัวฉีด | ใช้ลิงก์หน้าผู้ผลิตเป็นภาพอ้างอิงภายนอก; ยังไม่อนุญาตฝังภาพในหนังสือ | หน้านี้มี piezo ด้วย ห้ามหยิบผิดชนิด ภาพ solenoid ทั่วไปไม่ยืนยัน G2/G3 หรือเลขหัวฉีด 1KD/2KD ใด; ไม่อ่านเลขอะไหล่ที่มองไม่ชัดขึ้นเอง | ถ่ายหัวฉีดจริงทั้งตัว จุดต่อ high-pressure จุดกลับ ปลั๊ก และรหัสชดเชยที่คมชัด พร้อมบันทึก application และปกปิดข้อมูลระบุตัวรถที่ไม่จำเป็น เชื่อมรูป 07/15 |
| **PH04 — Rail assembly และอุปกรณ์ระบาย** | [DENSO 00400706E](https://www.service-engine.com.ua/webroot/pdf/TOYOTA%201KD%202KD%20ENGINE.pdf) หน้า 1–8 เป็นภาพเชิงเทคนิคของ rail/pressure discharge valve; [Toyota DR201E](https://toyotamanuals.gitlab.io/hiluxoct2010/rm/dr201e/m_05_0005.pdf) หน้า 05–11/12 เป็นผังระบบที่มี limiter | หลักฐานนี้เป็นภาพวาด/ผัง ไม่ใช่ภาพถ่ายจริง ไม่ดึงหน้าคู่มือมาฝังแทนภาพอุปกรณ์จริง ใช้ลิงก์เอกสารอ้างหลักการ | ต้องแยก mechanical limiter กับ commanded discharge valve ตามชุด rail จริง ปีรถหรือชื่อเครื่องเพียงอย่างเดียวไม่พอ | ถ่าย rail ทั้งเส้นและปลายทั้งสอง ให้เห็นอุปกรณ์ระบาย/ปลั๊กจริง พร้อมป้าย/เอกสารที่จับคู่ rail variant; หากมีทั้งสองชนิดให้ทำภาพเทียบแยกคันชัดเจน เชื่อมรูป 06/13 |
| **PH05 — Rail pressure sensor / ปลั๊ก** | [Toyota DR201E หน้า 05–70 ถึง 77](https://toyotamanuals.gitlab.io/hiluxoct2010/rm/dr201e/m_05_0070.pdf) และ [RM1151E หน้า 05–486 ถึง 492](https://toyotamanuals.gitlab.io/PZ471-Z00W0-CA/htmlweb/rm/rm1151e/m_05_0486.pdf) ใช้ยืนยันว่ามีการจัดวงจรต่างกัน; ยังไม่มีภาพถ่ายตรงชิ้นส่วนที่สิทธิ์และ application ผ่านครบ | ใช้ผังวาดใหม่ 03/08/11 ต่อไปและลิงก์เอกสารประกอบ ไม่เรียกผังหรือรูป connector ใน manual ว่าภาพถ่ายชิ้นส่วนจริง | ห้ามเอาภาพ sensor สามสายทั่วไปแทนทุก variant; connector ID จากเอกสารหนึ่งไม่ใช่มุมมองปลั๊กของอีกชุด | ถ่ายขณะติด rail, ด้านปลั๊ก/ด้านสายโดยระบุมุมมอง และจุดวัดที่ไม่ทำให้ขั้วเสียหาย จับคู่หมายเลขชิ้นส่วนและ EWD จริงก่อนใส่ cavity เชื่อมรูป 03/08/11 |

รายการ PHxx เป็นรหัสงานภาพ ไม่ใช่ source ID หรือ part number **ไม่มี part number ใดถูกเสนอจากการเดาในแผนนี้**

## แยกภาพจริงออกจากภาพวาดใหม่ในฉบับหนังสือ

- **ภาพวงจร 01–16 / ชุด print:** เป็นภาพวาดใหม่หรือ workflow ของผู้จัดทำ ไม่เรียกภาพจริงหรือภาพถ่าย ECU/ชิ้นส่วน ไม่ใช้ AI photorealistic illustration มาเติมแล้วติดคำว่าภาพจริง
- **PH01–PH03:** เป็นแหล่งภาพนำเสนอผลิตภัณฑ์ที่พบจากผู้ผลิต ใช้ลิงก์ได้ในฐานะแหล่งดูประกอบ ไม่ได้ผ่านสิทธิ์ฝังและไม่ได้จับคู่กับรถเฉพาะคันแล้ว
- **PH04–PH05:** ยังเป็นช่องว่างภาพถ่ายตรง application; มีเพียงหลักฐานภาพวาด/ผังและภาพวาดใหม่ของเรา
- **ภาพถ่ายเองหรือภาพรับอนุญาตภายหลัง:** ต้องบันทึกคนถ่าย ผู้ถือสิทธิ์ วันที่ รุ่น/ชิ้นส่วน และขอบเขตอนุญาตพิมพ์/ดิจิทัล/คอร์สให้ครบ จึงเปลี่ยนสถานะเป็นพร้อมฝัง

## เกณฑ์รับภาพก่อนนำไปจัดหน้า

1. เห็นจริงและยืนยันว่าถ่ายชิ้นส่วนจริง ไม่ใช่ render/ภาพวาดที่แต่งให้เหมือนจริง
2. อ่าน marking หรือมีหลักฐาน application กำกับ หากไม่มีให้ลงคำว่า “ภาพตัวอย่างตระกูลชิ้นส่วน” ไม่ใช้ยืนยันเบอร์ที่ติดรถ
3. ระบุ NC/NO หรือ rail variant จากเอกสาร/หมายเลขชิ้นส่วนที่ตรวจแล้ว ไม่อาศัยสีปลั๊กหรือความยาวอย่างเดียว
4. ได้สิทธิ์ฝังตรงกับรูปและขอบเขตใช้ ไม่ทดแทนด้วยการใส่เครดิตอย่างเดียว
5. คำบรรยายชี้จุดที่สัมพันธ์ P0093 จริง เช่น ทางเข้า/ทางกลับ/SCV/จุดวัด ไม่เพิ่มภาพชิ้นส่วนที่ไม่ช่วยวินิจฉัยเพื่อให้จำนวนมากขึ้น
6. ไม่ใช้ภาพทดสอบที่แสดงการคลายท่อแรงดันสูงขณะเครื่องทำงาน การอุดทางระบาย หรือการต่อไฟตรงแบบไม่มีขั้นตอนรองรับเป็นภาพตัวอย่างให้ผู้เรียนทำตาม

## การตัดสินใจผลิตฉบับนี้
