# แผนภาพวงจร P0093 — 1KD / 2KD

ปรับปรุง 21 ตุลาคม 2026 (เวลาไทย) • รอบสองสร้างครบ 16 ภาพ SVG พร้อม PNG

ภาพทั้งหมดวาดขึ้นใหม่ ไม่ใช่สำเนาภาพจากคู่มือ ภาพ 01–10 อธิบายหลักการและไม่ใช่ผังสาย OEM; ภาพ 11–12 เป็นตัวอย่างการต่อสายที่ตรวจเลขขาจาก DR201E เฉพาะ Hilux TASA Argentina ชัดเจน ไม่ครอบรถทุกคัน สีสาย ค่าโอห์ม และรูปคลื่นมาตรฐานยังไม่ใส่จนกว่าจะจับคู่เอกสารและ application ได้

## ภาพที่สร้างและคำบรรยายใต้ภาพ

### 01 — เส้นทางน้ำมันครบวงจร

ไฟล์ `01_hydraulic_paths.svg` / `.png` • ฐานข้อมูล C03 / C04 / C07

**คำบรรยาย:** ภาพวาดใหม่แยกด้านดูดแรงดันต่ำ ท่อแรงดันสูง และน้ำมันไหลกลับ ไม่ใช่ผังติดตั้งรถเฉพาะคัน จุด A–D เป็นจุดอ้างอิงในภาพ ไม่ใช่ชื่อพอร์ต OEM

**ใช้สอน:** ก่อนกล่าวหาว่าปั๊มเสีย ต้องรู้ว่าปั๊มได้รับน้ำมันพอหรือไม่ การรั่วด้านดูดอาจดูดอากาศเข้าโดยไม่เห็นน้ำมันเปียกด้านนอก ส่วน return เป็นทางเดินปกติ แต่ปริมาณมากเกินต้องพิสูจน์ตามขั้นตอนและสเปกรุ่นนั้น

### 02 — วงป้อนกลับควบคุมแรงดัน

ไฟล์ `02_pressure_feedback.svg` / `.png` • ฐานข้อมูล C01 / C03 / C06 และหลักการควบคุมทั่วไป

**คำบรรยาย:** ECU เทียบแรงดันเป้าหมายกับค่าที่เซ็นเซอร์รายงาน แล้วปรับการเติมรางผ่าน SCV ภาพนี้เป็นวงควบคุมเชิงหน้าที่ ไม่ใช่อัลกอริทึมหรือ calibration ภายใน ECU Toyota

**ใช้สอน:** คำสั่งเพิ่มแล้วแรงดันไม่ขึ้นไม่ได้พิสูจน์ว่าปั๊มเสียโดยลำพัง อาจเป็นการเติมไม่พอ การสูญเสียภายใน หรือข้อมูลป้อนกลับคลาดเคลื่อน ควรเก็บ target / actual / current พร้อมเงื่อนไขเดียวกัน

### 03 — วงจรเซ็นเซอร์รางสามเส้น

ไฟล์ `03_sensor_electrical.svg` / `.png` • ฐานข้อมูล C08 Toyota DR201E หน้า 05–73 และ C12 Toyota RM1151E หน้า 05–490: https://toyotamanuals.gitlab.io/PZ471-Z00W0-CA/htmlweb/rm/rm1151e/m_05_0486.pdf รวมหลักการวัดวงจรทั่วไป

**คำบรรยาย:** ผังหลักการสามหน้าที่ reference / signal / sensor return พร้อมตำแหน่งเปรียบเทียบแรงดัน อิงตัวอย่างสามสาย DR201E และระบุความต่างจาก RM1151E หลายสาย ไม่กำหนดว่าเป็นปลั๊กสามขาทุก variant และไม่ให้หมายเลข cavity

**ใช้สอน:** วัด reference เทียบ sensor return, signal เทียบ sensor return และตรวจ return เทียบขั้วกลับ ECU แยกกัน หาก reference ร่วมตกต้องตาม EWD ว่าอุปกรณ์ใดใช้ supply เดียวกัน ไม่ตัดสินเซ็นเซอร์จากแรงดันเทียบตัวถังอย่างเดียว

### 04 — ตรวจวงขดลวด SCV ให้ครบสองขั้ว

ไฟล์ `04_scv_driver_measurement.svg` / `.png` • ฐานข้อมูล C01 / C02 และหลักการวัดโหลดเหนี่ยวนำทั่วไป

**คำบรรยาย:** ผังหลักการขดลวดและภาคขับ แสดง differential probe คร่อมสองขั้วกับ current clamp ที่สายเส้นเดียว ไม่สมมติว่าขั้วใดลงกราวด์ และไม่เปิดเผย topology OEM ที่ยังยืนยันไม่ได้

**ใช้สอน:** มีแรงดันสวิตช์แต่ไม่มีกระแสควรตรวจขดลวด สาย ขั้วต่อ และการตั้งเครื่องมือก่อน มี current ไม่ได้แปลว่าวาล์วขยับได้ครบหรือปั๊มสร้างปริมาณน้ำมันได้พอ ขา scope แบบต่อ earth อาจลัดวงจรภาคขับ ต้องใช้การวัดที่เหมาะสม

### 05 — เปรียบเทียบ SCV NC / NO

ไฟล์ `05_scv_nc_no.svg` / `.png` • ฐานข้อมูล C01 / C02 / C05

**คำบรรยาย:** NC และ NO อ้างถึงสภาพเมื่อไม่จ่ายไฟ ภาพเปิด/ปิดเป็นภาพสอนหน้าที่ ไม่ใช่ภาพตัดขวางรูปร่างวาล์วจริง

**ใช้สอน:** ห้ามใช้กฎถอดปลั๊กแล้วแรงดันขึ้นหรือลงแบบเดียวกับรถทุกคัน ต้องตรวจ pump / SCV part number และคู่มือของคันจริง ขนาด SV1 / SV2 เป็นอีกคุณลักษณะหนึ่ง ไม่ใช่คำแปลของ NC / NO

### 06 — แยก limiter กับ discharge valve

ไฟล์ `06_limiter_discharge.svg` / `.png` • ฐานข้อมูล C05 §3.1 / C06

**คำบรรยาย:** เปรียบเทียบทางกลับที่ทำงานด้วยแรงไฮดรอลิกกับวาล์วระบายที่มีการสั่งไฟฟ้า ภาพแสดงสอง variant แยกกัน ไม่ได้ติดตั้งทั้งสองอย่างใน rail เดียวเสมอ

**ใช้สอน:** limiter เปิดอาจเป็นผลจาก overpressure ก่อนหน้า จึงต้องดูเหตุการณ์ก่อนแรงดันตก ไม่เปลี่ยน limiter ทันทีทุกกรณี ส่วน discharge valve ต้องเพิ่มการตรวจคำสั่ง สายไฟ และ EDU ตามคู่มือรุ่นจริง

### 07 — การสั่งหัวฉีดและทาง return

ไฟล์ `07_injector_command_return.svg` / `.png` • ฐานข้อมูล C04 / C05 / C06 และหลักการหัวฉีด solenoid

**คำบรรยาย:** แยกคำสั่ง ECU → EDU → ขดลวด ออกจากการเคลื่อนวาล์วควบคุม น้ำมันกลับ และเชื้อเพลิงออกหัวฉีด เป็นผังหน้าที่ ไม่ใช่วงจรภายใน EDU หรือสเปก pulse

**ใช้สอน:** เมื่อพบ P0200 ร่วม ต้องเข้าทางตรวจวงจร EDU / injector ของรุ่นนั้น feedback ทางไฟฟ้าไม่ใช่มาตรวัดปริมาณฉีดหรือปริมาณรั่วกลับ และค่าชดเชยหัวฉีดปกติไม่ได้ตัดปัญหา leak-off ออกทั้งหมด

### 08 — ความคลาดเคลื่อนจาก sensor return

ไฟล์ `08_ground_offset.svg` / `.png` • หลักการวงจรไฟฟ้าทั่วไป; ไม่อ้างว่าเป็นความผิดปกติประจำรุ่น Toyota

**คำบรรยาย:** แบบจำลองขั้วต่อมีความต้านทาน ทำให้ศักย์ไฟฟ้าของ return คนละจุดไม่เท่ากัน จึงต้องวัด voltage drop ขณะเกิดอาการ

**ใช้สอน:** การวัดความต่อเนื่องตอนจอดอาจผ่านแต่ขณะสั่น/ร้อนไม่ผ่าน อย่าซ่อมด้วยการพ่วง sensor return ลงตัวถัง ต้องคืนสภาพขั้ว/สายตามผังจริง ทิศของ error ต้องพิจารณาจากวงจรและค่าที่วัด ไม่เหมาว่า ground เสียแล้วแรงดันอ่านสูงทุกกรณี

### 09 — ลำดับก่อนเข้าสู่ fail-safe

ไฟล์ `09_pressure_event_sequence.svg` / `.png` • C06 สำหรับแนวคิด monitor / cut-off; เส้นกราฟเป็นข้อมูลสังเคราะห์ของผู้จัดทำ

**คำบรรยาย:** ตัวอย่างกราฟสังเคราะห์ของ hypothetical NC application แสดง target / actual / SCV current / injection เพื่อฝึกอ่านลำดับเหตุการณ์ ไม่มีค่าจริง แกนเวลาไม่ใช่เวลาทริกเกอร์ของ ECU รูปร่างกระแสไม่ใช่สเปกผ่าน/ไม่ผ่านและไม่แทนการตอบสนองของ NO

**ใช้สอน:** แรงดันต่ำหลัง ECU ตัดการฉีดไม่บอกต้นเหตุ ดูวินาทีก่อนโค้ดขึ้นและแยกเหตุออกจากผล การตอบสนอง current ในภาพไม่ควรคัดลอกใช้กับ NO application โดยไม่มีการแปลงทิศการควบคุม

### 10 — สมดุลปริมาณเข้าออก rail

ไฟล์ `10_fuel_balance.svg` / `.png` • C03 / C04 และหลักการสมดุลการไหลทั่วไป

**คำบรรยาย:** ภาพโมเดลอธิบายรางเป็นตัวสะสมแรงดัน: ปั๊มส่งเข้า, หัวฉีดจ่ายออก, return ภายใน และวาล์วระบาย ละการบีบอัด/อุณหภูมิ/คลื่นแรงดันเพื่ออ่านง่าย ไม่ใช่สมการวินิจฉัย ECU

**ใช้สอน:** แรงดันตกมีได้จาก supply ลด outflow เพิ่ม หรือสัญญาณวัดผิด ชื่อโค้ดไม่ได้ระบุว่าต้องมีรูรั่วภายนอกขนาดใหญ่

## ตัวอย่างการต่อสายเฉพาะเอกสารที่เพิ่มแล้ว

### 11 — ตัวอย่างการต่อเซ็นเซอร์ราง DR201E

ไฟล์ `11_dr201e_rail_connections.svg` / `.png` • ฐานข้อมูล C08: Toyota DR201E หน้า 05–73/75 https://toyotamanuals.gitlab.io/hiluxoct2010/rm/dr201e/m_05_0070.pdf

**คำบรรยาย:** ผังต่อสายวาดใหม่จากเอกสาร Hilux 1KD/2KD TASA made for Argentina เท่านั้น: F9–3 VC ถึง E8–18 VC ผ่าน J6; F9–2 PR ถึง E8–26 PCR1; F9–1 E2 ถึง E8–28 E2 ผ่าน junction J7/J8 ไม่ใช่หมายเลขขารุ่นไทยทุกคัน

**ใช้สอน:** วงจรนี้เป็นตัวอย่างที่ยืนยัน connector ID แล้ว แต่ยังต้องเทียบ application และมุมมองขั้วปลั๊กก่อนใช้จริง ไม่กำหนดซ้าย/ขวาหรือด้านสายจากภาพแผนผัง RM1151E มีตัวอย่างเซ็นเซอร์หลายสายต่างกันจึงไม่ย้ายเลขขาข้ามเอกสาร

### 12 — ตัวอย่างวงขดลวด SCV DR201E

ไฟล์ `12_dr201e_scv_connections.svg` / `.png` • ฐานข้อมูล C09: Toyota DR201E หน้า 05–80/82 https://toyotamanuals.gitlab.io/hiluxoct2010/rm/dr201e/m_05_0078.pdf

**คำบรรยาย:** ผังขดลวด SCV วาดใหม่จาก DR201E Hilux TASA Argentina: S8–1 ถึง E8–2 PCV+ และ S8–2 ถึง E8–1 PCV– เป็นข้อมูลเฉพาะชุดเอกสาร ไม่วาดภาคขับภายใน ECU ที่คู่มือไม่ได้ให้รายละเอียด

**ใช้สอน:** PCV– เป็นชื่อวงจรไม่ใช่หลักฐานว่าเป็นกราวด์ตัวถัง การวัดคลื่นต้องใช้การวัดคร่อมที่เหมาะสมและ current clamp เส้นเดียว การทดสอบโอห์มหรือสายแบบดับเครื่องต้องแยกจากการวัดขณะระบบทำงานและใช้สเปกตรงรุ่น

ภาพ 11–12 เพิ่มจากหลักฐานภาพหน้าคู่มือที่ฝ่ายวิจัยตรวจแล้ว ไม่ฝังภาพ OEM ต้นฉบับในไฟล์ตีพิมพ์

## ภาพเพิ่มเติมรอบสอง

### 13 — แรงดันสูงก่อนแรงดันตก

ไฟล์ `13_overshoot_then_drop.svg` / `.png` • ฐานข้อมูล C06 และ C02

**คำบรรยาย:** เส้นทางหนึ่งที่ควรตรวจเมื่อ P1229 ร่วมกับ P0093 ในระบบที่มี mechanical limiter: ส่งน้ำมันมากเกิน แรงดันสูง เปิดทางระบาย แล้วแรงดันตก กราฟเป็นเส้นสังเคราะห์ไม่มีค่า OEM และไม่ใช่หลักฐานว่า limiter เปิดจริงในรถที่กำลังตรวจ

**ใช้สอน:** ให้ผู้เรียนหาหลักฐานก่อนเวลาตัด ไม่สรุปจากแรงดันต่ำตอนจบ หากรถเป็น discharge valve สั่งไฟฟ้าต้องเปลี่ยนทางตรวจตามระบบ ไม่ใช้ภาพ limiter แทนทุก variant

### 14 — จุดวัดแรงดันด้านดูด

ไฟล์ `14_suction_measurement.svg` / `.png` • ฐานข้อมูล C10: Pico AGT-833 https://www.picoauto.com/library/automotive-guided-tests/pressure-transducers/wps500x-pressure-transducer/AGT-833-negative-priming-fuel-pressure-diesel/ และหลักการความดันตกคร่อมทั่วไป

**คำบรรยาย:** แผนวัดก่อนและหลังกรองในระบบดูดน้ำมันที่ยืนยัน configuration แล้ว เป็นผังหลักการตำแหน่งวัด ไม่ใช่ชุด sight-block / stop-tap ของ Pico และไม่ให้เกณฑ์ vacuum ผ่านหรือไม่ผ่าน

**ใช้สอน:** บันทึกตำแหน่งจริง ชนิดเกจ รอบ โหลด อุณหภูมิ และสภาวะเดียวกันก่อนเปรียบเทียบ ความดันต่างก่อน–หลังต้องตีความร่วมการไหล และการรั่วด้านดูดอาจนำอากาศเข้าโดยไม่เห็นน้ำมันภายนอก ภาพไม่สอนปิดท่อเพื่อทำให้เครื่องดับและไม่อนุญาตเกจแรงดันต่ำต่อเข้ารางแรงดันสูง

### 15 — เงื่อนไขของการทดสอบน้ำมันกลับ

ไฟล์ `15_return_test_conditions.svg` / `.png` • ฐานข้อมูล C11: Pico AGT-786 https://www.picoauto.com/library/automotive-guided-tests/pres/wps500x-pressure-transducer/AGT-786-crd-injector-back-leakage/

**คำบรรยาย:** ผังเลือกวิธีทดสอบและเก็บเงื่อนไขน้ำมันกลับก่อนแปลผล ข้อจำกัด solenoid / low-return-pressure เป็นขอบเขตวิธี AGT-786 ไม่ใช่การประกาศว่า injector return ทุกแบบถอดลงภาชนะเปิดได้

**ใช้สอน:** ไม่สร้างค่า mL กลางสำหรับทุกชุดหัวฉีด การเปรียบเทียบต้องเก็บ rail target / actual, รอบ, โหลด, อุณหภูมิ, เวลา และแรงดันทางกลับ การทดลองที่ทำให้แรงดันทางกลับซึ่งระบบต้องการหายไปอาจผิดวิธี ต้องเลือก manual / adapter ของ application จริง

### 16 — ผังวินิจฉัยด้วยหลักฐาน

ไฟล์ `16_p0093_evidence_workflow.svg` / `.png` • ฐานข้อมูล C06 / C01 / C08 / C09 / C11 และข้อเสนอวิธีคิดของบรรณาธิการ

**คำบรรยาย:** ผังภาพสรุปของผู้เขียนตั้งแต่ยืนยันระบบ เก็บ freeze frame / รหัสร่วม แยกความน่าเชื่อถือสัญญาณ แยกปริมาณเข้าออก และตรวจผลหลังซ่อม ไม่ใช่ผังขั้นตอน Toyota ที่ใช้แทน repair manual ทุกข้อ

**ใช้สอน:** นำกรณีศึกษาให้ผู้เรียนเลือกหลักฐานก่อนเลือกอะไหล่ หากมี P0200 ต้องใช้ทาง EDU / injector ที่เกี่ยวข้อง และถ้ามี overshoot ก่อนตกให้พิสูจน์เหตุการระบาย หลังแก้ต้องทดสอบเงื่อนไขเดิมอย่างปลอดภัย ไม่จบที่ลบโค้ด

## แนวทางเพิ่มภาพหลังรอบสอง

- วงจรไฟเข้า ECU / EDU: fuse, relay contact, power ground และการวัด voltage drop — ต้องหา EWD เฉพาะรุ่นก่อนใส่ cavity
- เซ็นเซอร์และภาครับ ADC: input protection / RC filter แบบวงจรสอนทั่วไป แยกจากข้อมูลภายใน ECU OEM
- คลื่น SCV voltage / current: กระแส RL, การสวิตช์และการตัดวงจร พร้อมข้อมูลจำลองชัดเจน
- เปรียบเทียบ return หัวฉีดสี่สูบ: ภาพการต่อจริงเมื่อมีวิธีและสเปกตรง part number ไม่ตั้งค่า mL กลางขึ้นเอง
- EDU และหัวฉีด: จุดวัด differential และ current พร้อมวิธีแยก open / short โดยไม่จ่ายไฟตรงหัวฉีด
- ทดสอบความสัมพันธ์ rail signal กับ scan PID แบบเหตุการณ์ร่วม ตรวจ intermittent harness โดยไม่แก้ signal หลอก ECU
