# ชุดภาพวงจรสำหรับ A4 แนวนอน

วันที่ 21 ตุลาคม 2026 • ตอบข้อ CL01 จากการตรวจต้นแบบ • สถานะ: SVG/PNG ครบ 16 ภาพ เปิดตรวจภาพ render แล้วครบทุกภาพ

## ไฟล์ส่งต่อฝ่ายผลิต

- `print_manifest.json` ที่ราก `circuits/` เป็น manifest หลักสำหรับ builder
- `print/` มี SVG และ PNG ชื่อเดิมครบภาพ 01–16; manifest อ้าง `png: print/<ชื่อ>.png` และ `svg: print/<ชื่อ>.svg`
- `print/print_manifest.json` เป็นสำเนา metadata ชุดเดียวกัน โดย path ยังคงอ้างจากราก `circuits/`
- `print/render_audit.json` ผลล่าสุด `[]` ไม่มีตัวหนังสือหลุด canvas
- `build_print_assets.py` สร้างชุดพิมพ์จากต้นฉบับ; `print/render_print.cjs` เรนเดอร์ PNG ตามความสูงจริงของแต่ละภาพ

ต้นฉบับ SVG/PNG ชุดเดิมและ notes เดิมนอกโฟลเดอร์ `print/` ไม่ถูกแก้ในงานรอบนี้

## สิ่งที่เปลี่ยนเฉพาะชุดพิมพ์

ตัดแถบคำอธิบายที่เริ่ม y=1040 และ footer y=1220 ออกจากสำเนาสำหรับพิมพ์ ปรับ viewBox ให้จบหลังส่วนวาดจริงตามภาพ ไม่ตัด node, สายวัด, รูปคลื่น, label จุดทดสอบ หรือข้อความจำกัดขอบเขตในส่วนวาด

บรรทัด scope ใต้หัวเรื่องคงความหมายสำคัญและเขียนไทยชัดขึ้น เช่น ภาพ 09 ยังคงสมมติ NC / synthetic / ไม่แทน NO; ภาพ 11–12 ยังคง DR201E / Hilux TASA Argentina / หน้าเอกสาร; ภาพ 01 คง legend สี low/high/return ภาพ 08 ระบุแบบจำลองวงจรทั่วไป ไม่ใช่ OEM

ตัวอักษรที่เหลือทั้งหมดอย่างน้อย 22 px ใน canvas กว้าง 1800 px เมื่อวางโดยรักษาสัดส่วนในกรอบกว้างไม่เกิน 269 mm และสูงไม่เกิน 150 mm จะได้ตัวอักษรต่ำสุดประมาณ 9.04–9.32 pt ไม่ควรลดกรอบภาพให้เล็กกว่านี้เพื่อยัด caption เพิ่ม

## เงื่อนไขที่ builder ต้องรักษา

1. ใช้ภาพพิมพ์บนหน้า A4 แนวนอน ไม่ย้อนกลับไปย่อ A4 แนวตั้ง
2. จำกัด image width/height แบบรักษาสัดส่วน และตรวจขนาดจริงหลังสร้าง PDF ไม่ใช้ DPI เป็นตัวแทนขนาดตัวอักษรบนกระดาษ
3. แสดง `caption_th` พร้อมแหล่งอ้างอิงภายนอกภาพต่อไปเสมอ; คง `teaching_note_th` ในบทหรือคำอธิบายที่เชื่อมถึงกัน
4. `removed_below_drawing_text` เก็บข้อความที่นำออกจากภาพเพื่อไม่ให้สูญเนื้อหาโดยไม่ทราบ แถบนี้มี notes/ข้อควรระวังเดิม ให้เก็บในคำอธิบายภายนอกหรือบทสอนตามความเหมาะสม ไม่ถือว่าเป็นข้อมูลที่ไม่มีความสำคัญทั้งหมด
5. ข้อจำกัด 09 NC และ 11–12 DR201E ไม่ควรถูกครอบ/clip ตอนจัดหน้า มีข้อความอยู่ในภาพด้วยแล้ว
6. `source_ids` ใช้ canonical IDs เมื่อ URL ตรงทะเบียนฝ่ายวิจัย; แหล่งที่ยังไม่ลงทะเบียนอยู่ `unregistered_source_urls` ห้ามสร้าง ID เหมารวมเอง
