# โครงหนังสือและเกณฑ์ปิดเล่ม

## ลำดับบท

1. วิธีใช้หนังสือ ขอบเขตรุ่นเครื่องยนต์ และการทำงานกับ common rail อย่างปลอดภัย
2. อ่านรหัส P0093 โดยเริ่มจากเงื่อนไขตรวจและหลักฐานของรถคันนั้น
3. แผนที่ความแตกต่าง 1KD 2KD ตลาดรถและรุ่นเอกสาร
4. วงจรเชื้อเพลิงตั้งแต่ถัง กรอง ปั๊ม ราง หัวฉีด และทางกลับ
5. ปั๊มจ่ายและ SCV แต่ละชนิด กลไกและลำดับการทำงาน
6. วงจรไฟฟ้า ECU เซนเซอร์แรงดันราง และภาคควบคุม
7. แรงดันเป้าหมาย แรงดันจริง และการป้อนกลับในแต่ละสภาวะ
8. Freeze frame ข้อมูลสแกน กราฟ และการตั้งสมมติฐาน
9. ผังวินิจฉัยเริ่มต้น รวมโค้ดร่วมและลำดับตรวจที่ตรงคู่มือ
10. แยกปัญหาทางดูด กรอง การปนเปื้อนและอากาศเข้า
11. แยก SCV ปั๊มและภาคควบคุมด้วยหลักฐาน
12. แยกหัวฉีด ทางกลับ และวาล์วรางตามระบบ
13. แยกเซนเซอร์ ปลั๊ก สายไฟ กราวด์ และอาการเป็นครั้งคราว
14. วิธีแก้ตามสาเหตุที่ยืนยัน และเงื่อนไขใช้เครื่องมือเฉพาะ
15. การทดสอบยืนยันหลังซ่อมและการติดตามอาการภายใต้โหลด
16. เคสฝึกจำลอง ผังตัดสินใจ และแบบบันทึกผลวัด

ภาคผนวก: ตารางสเปกที่แยกตามแหล่งและรุ่น แหล่งภาพและวงจร อภิธานศัพท์ และรายการที่ยังไม่ยืนยัน

## แบบบทเรียน

ทุกหัวข้อใช้โครง: ทำงานอย่างไร → เสียแบบใดได้ → ใช้หลักฐานอะไรแยก → ตรวจอย่างไร → แก้อย่างไรเมื่อยืนยัน → ตรวจหลังแก้อย่างไร พร้อมภาพขยายและคำบรรยาย วงจรไฟฟ้าต้องไม่ถูกแทนด้วย block diagram เพียงอย่างเดียว แต่จะแยก functional overview ออกจากวงจรระดับจุดต่อให้ชัดเจน

## สิ่งที่ห้ามเหมารวม

ค่าความดันและสภาวะวัดของคนละคู่มือ ผลเมื่อถอดปลั๊ก SCV ทิศ duty cycle หมายเลขขา สีสาย และความใช้ได้ของขั้นตอนเฉพาะเครื่องยนต์ ต้องแยกตามหลักฐาน ไม่ใช้ค่าสากลที่เดาขึ้น

## แผนปิดเล่มตามเวลาไทย

- ระยะแรกถึง 03:00: สืบค้นคู่มือ ตรวจแหล่ง และเขียนเนื้อหาที่พิสูจน์ได้
- 03:00 ถึง 05:00: ขยายวงจร ลำดับการทำงาน และตารางแยกสาเหตุ/วิธีแก้
- 05:00 ถึง 06:00: รวมต้นฉบับ ตรวจความขัดแย้ง และเติมเฉพาะช่องว่างสำคัญ
- 06:00 ถึง 06:30: จัดเล่มและตรวจภาพ/การอ้างอิง
- 06:30 ถึง 07:00: ตรวจไฟล์สุดท้ายและส่งมอบ ระบุช่องว่างที่ยังไม่ยืนยัน

จำนวนหน้าให้ตามเนื้อหาที่ตรวจสอบได้ ไม่เพิ่มหน้าว่างหรือภาพซ้ำเพื่อให้ได้จำนวนหน้า
