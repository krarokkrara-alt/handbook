# ส่งต่องาน Claude

อ่าน CLAUDE.md ในโฟลเดอร์นี้เป็นคำสั่งหลักของงานใหม่ หนังสือ PDF และไฟล์ประกอบเป็นสำเนาตั้งต้นของฉบับขยาย 57 หน้า ไม่ใช่ผลค้นคว้าเพิ่มเติมของ Claude

งานใหม่คือค้นวงจรและภาพเพิ่มเติมจากบอร์ดที่มี เพิ่มโปรแกรมและขั้นตอนย้ายข้อมูล/โคลนที่มีหลักฐาน แสดงผลเปรียบเทียบไฟล์อย่างชัดเจน และตรวจทานโดย Agent แยกงานก่อนจัดทำหนังสือรุ่นถัดไป

คิวกลางอยู่ ../../CLAUDE_AUTO_START/latest.json การเข้าคิวไม่ใช่การเริ่มทำงาน หาก Claude CLI ยังไม่ลงชื่อเข้าใช้ ให้เจ้าของเปิด Claude แล้วเริ่มด้วยคำสั่งใน README แทน ตัวส่งคิวอัตโนมัติเดิมจำกัดเครื่องมือสำหรับตรวจอ่าน ไม่ใช่ตัวรันค้นเว็บและแก้หนังสือเต็มรูปแบบ
