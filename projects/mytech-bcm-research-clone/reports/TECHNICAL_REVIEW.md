# ตรวจเทคนิค (รอบ 20 พฤศจิกายน 2569)

ผู้ตรวจ: Claude (AI) ไม่ใช่วิศวกรหรือผู้ผลิตรถ ไม่ได้ทดสอบบนรถหรือชิ้นงานจริง

## ระบบเปรียบเทียบ

- ตรวจกับไฟล์จำลอง: ช่วงต่าง 0x400–0x40F (16 ไบต์), 0x120–0x12F + 0x1F00–0x1F3F (80 ไบต์) ตรงกับที่ตั้งใจสร้าง
- `validate.py` ทดสอบกรณีขนาดไม่เท่ากัน (ไบต์ที่ขาดนับเป็นผลต่าง) และยืนยันว่าผล JSON ไม่มีค่าไบต์
- คำสั่งคู่เดียวแบบเดิมยังให้ผลรูปแบบเดิม (เพิ่มฟิลด์เมื่อใส่ `--kind` หรือ `--regions` เท่านั้น)
- ป้องกันการเขียนผลทับไฟล์ input ทุกไฟล์ในไฟล์งาน
- ข้อจำกัด: วนลูประดับไบต์ใน Python เหมาะกับไฟล์ระดับ KB–ไม่กี่ MB ซึ่งครอบคลุม EEPROM/D-FLASH BCM ทั่วไป

## ข้อความเทคนิคที่เพิ่ม

- ตารางจุดหยุดงานสอดคล้องกับข้อห้ามใน CLAUDE.md (ไม่ถือ read-write coverage เป็น full clone, สำรองกล่องทดแทนก่อน, ไม่ตีความ offset)
- ไม่ได้อ้างค่าแรงดัน ขาชิป หรือชื่อเมนูใหม่

## ยังไม่ได้ตรวจ

ไม่ได้ตรวจเนื้อหาเทคนิคเดิมบท 1–15 และภาคขยายวงจรซ้ำ ใช้ผลตรวจเดิมใน QA_REPORT.md และ EDITORIAL_REVIEW_V2.md (เป็นหลักฐานของเล่มตั้งต้นเท่านั้น)
