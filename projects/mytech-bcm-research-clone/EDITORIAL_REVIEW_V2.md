# ผลตรวจบรรณาธิการฉบับ 2

วันที่ 19 พฤศจิกายน 2569

ผลตรวจ: ข้อบกพร่องสำคัญที่แจ้งในรอบ 2 ได้แก้ในต้นฉบับและตัวสร้างแล้ว ผ่านการตรวจความสอดคล้องของข้อความกับภาพและขอบเขตคำกล่าวอ้างตามรายการด้านล่าง ผลนี้ไม่ใช่การทดสอบซ่อมหรือ full road test และไม่ใช่การรับรองโดยวิศวกร

## รายการที่ตรวจแก้แล้ว

- หัวข้อ Reset ใช้ TPS3808-Q1 เอกสาร SBVS085J Figure 14 ให้ตรงกับภาพ TPS3808G33 อธิบาย SENSE, MR, CT และ RESET open-drain แยกจาก RESET ของ LM53603 และไม่เดา threshold หรือเวลาหน่วง
- ภาพเชื่อมต่อ ACDP ที่ระบุ MC9S12XDT256 มีคำบรรยายชัดว่าเป็นคนละฮาร์ดแวร์กับ MC9S12XEQ384 mask 3M25J และไม่ใช้แทนจุดต่อ XEQ384
- ภาพผัง MCU ของ CG-PRO ระบุ MC9S12DG64 80 QFP ตามภาพจริง ภาพ Hex Editor บรรยายเป็นการเปรียบเทียบข้อมูลที่ต่างกัน ไม่อ้างผลอ่านหรือ verify สำเร็จ ส่วนแถบเครื่องมือไม่เพิ่มปุ่ม Full Clone หรือ Verify ที่ไม่มีในภาพ
- TPS1H100-Q1 แยก Version A/ST กับ Version B/CS ไม่แสดงว่าชิปตัวเดียวมีสองขาพร้อมกัน เนื้อหาวงจรแยกค่าตัวอย่าง typical ออกจาก absolute maximum และไม่ใช้ค่าจาก reference design เป็นเกณฑ์ BCM ทุกกล่อง
- ตัวสร้าง PDF แทรกเอกสารผู้แต่งเดิมสี่หน้าต่อจากปกก่อนหน้าวิธีอ่าน ส่วน HTML วางภาพเอกสารผู้แต่งหลังปก ข้อความขอบคุณเดิมไม่ถูกใช้ยืนยันว่า Claude หรือบุคคลที่กล่าวถึงตรวจหนังสือ BCM ฉบับนี้
- ตัวสร้างมีตาราง PDF และ HTML จริง พร้อมหัวตารางซ้ำเมื่อ PDF ขึ้นหน้าใหม่ ตัวตรวจ `tools/validate.py` มีการเปรียบเทียบ content streams ของ PDF หน้า 2–5 กับเอกสารผู้แต่งต้นฉบับ ซึ่งช่วยตรวจว่าลำดับและเนื้อหาหน้าถูกคงไว้ แต่ไม่ทดแทนการตรวจภาพและ QR ด้วยสายตา

## ขอบเขตการตรวจและเกณฑ์ส่งเล่ม

ตรวจ `manuscript.md`, `supplement-v2.md`, `tools/build_book.py`, `tools/validate.py`, `FIGURE_MANIFEST.json` และภาพ schematic/CG-PRO ที่เกี่ยวข้อง แหล่งปฐมภูมิสำคัญได้แก่ datasheet ของ TI/NXP/ST คู่มือ CG-PRO และหน้า Module08 ของ Yanhua การผ่านรายการนี้ไม่ได้ยืนยันเมนูทุกเวอร์ชัน จุดต่อบอร์ดรถแต่ละหมายเลข หรือความเข้ากันได้ของกล่องทดแทน

ผู้ประสานงานหลักต้องสร้าง PDF จากต้นฉบับล่าสุดและทำ visual QA รอบสุดท้าย ตรวจหน้า 2–5 ภาพผู้แต่งและ QR สารบัญ bookmarks ภาพวงจร ตาราง ข้อความและคำบรรยายไม่ขาดหรือทับกัน รวมทั้งรันตัวตรวจให้ผ่านก่อนส่งหรือเผยแพร่ รายงานนี้ไม่อ้างว่าได้ตรวจภาพ PDF ที่กำลังสร้างใหม่หรือรับรองจำนวนหน้าสุดท้าย

ภาพวงจรเป็น excerpt จากเอกสารผู้ผลิตตาม manifest ไม่ใช่วงจรที่ตรวจ continuity จาก BCM รถจริงทั้งหมด รายการรองรับเครื่องมือไม่ใช่ผล full clone สำเร็จ และการตรวจไฟล์หรือ pin detection ไม่ใช่ผลทดสอบฟังก์ชันรถครบระบบ
