# อ่านวงจรจากภาพกล่องจริง 01–07

[เปิดหนังสือ PDF 33 หน้า](output/ECU_01_07_Photo_Atlas.pdf)

ใช้ภาพจริงที่ผู้ใช้ส่ง 19 ภาพ ทำแผนที่บริเวณสำรวจของกล่อง 7 ใบ พร้อมวงจรสอนอ่าน 4 แผ่นและตารางวางแผนพิสูจน์ เน้นภาพมากกว่าข้อความ ไม่มีการทดสอบกับกล่องจริง

## สถานะของข้อมูล

**ยังไม่ใช่ผังวงจรจริงหรือคู่มือจุดวัดของทั้ง 7 กล่อง** ยังไม่มีหมายเลขรุ่นครบ เบอร์ IC ชัด และผลวัดต่อถึงกัน จึงไม่ใส่แรงดัน 12/5/3.3 V บนแพดจริงจากการคาดเดา กรอบประสีส้มเป็นชื่อบริเวณสำรวจ ไม่ใช่หมายเลขขา OEM หรือคำตัดสินหน้าที่ชิ้นส่วน

วงจรสอนมีค่าในเงื่อนไขตัวอย่างและคำอธิบายจุดวัด แต่ห้ามนำตัวเลขในวงจรสอนไปตัดสินกล่องจริงโดยตรง:

| แผ่นวงจร | หลักการที่อธิบาย |
|---|---|

## แยกแฟ้มรายกล่อง

- [กล่อง 01](cases/ecu-001/README.md): พบข้อความ FUJITSU TEN LIMITED มี IC ขาสี่ด้านใหญ่สามตำแหน่ง เบอร์ยังไม่ยืนยัน
- [กล่อง 02](cases/ecu-002/README.md): พบข้อความ FUJITSU TEN LIMITED มีบริเวณคราบ/ผิวเคลือบที่ต้องตรวจใกล้ ยังไม่วินิจฉัยความเสียหาย
- [กล่อง 03](cases/ecu-003/README.md): ปลั๊กดำสองช่องและคาปาซิเตอร์ SIKOREL ยังไม่มีหมายเลขกล่องเพื่อยืนยันระบบ
- [กล่อง 04](cases/ecu-004/README.md): อ่าน KEIHIN และฉลาก 37820-P3S-T51 ได้ ยังไม่จับคู่รถหรือ pinout
- [กล่อง 05](cases/ecu-005/README.md): พบ FUJITSU TEN รูปร่างคล้ายบางกล่องไม่ได้ยืนยันว่าใช้ผังเดียวกัน
- [กล่อง 06](cases/ecu-006/README.md): มีป้าย HIGH VOLTAGE / ELECTRIC SHOCK และสายเพิ่มเติม ไม่ให้ต่อไฟตามสีสาย ภาพตัวเรือนไม่ใช่หลัง PCB
- [กล่อง 07](cases/ecu-007/README.md): เห็นลวดเชื่อมละเอียดภายใน ห้ามแตะ/ขูด/วางโพรบบนลวด die หรือวัสดุคล้ายเจล แม้ถอดไฟแล้ว

## รูปแบบไฟล์

- `originals/` สำเนาภาพผู้ใช้เดิม ข้อมูลไฟล์ไม่ถูกเปลี่ยน ตรวจ SHA256 ตรงไฟล์รับเข้า
- `annotated/` ภาพกำกับ PNG และ SVG ซึ่งฝังภาพเดิมพร้อมชั้นกำกับเวกเตอร์
- `schematics/` วงจรสอน SVG/PNG แยกจากวงจรของฮาร์ดแวร์จริง
- `cases/` ข้อมูลและภาพรายกล่อง
- `catalog.json` ทะเบียนภาพ พิกัดโซนและสถานะความรู้
- `reviews/` ผลตรวจภาพและวงจรโดยเอเจนต์ ไม่ใช่การรับรองจากผู้ผลิต
- `output/` หนังสือ PDF และ HTML สำหรับเปิดอ่านในเบราว์เซอร์

## วิธีไล่วงจรจริงที่จะทำต่อ

ยืนยันชื่อขาปลั๊กและกราวด์ก่อน ไล่ขาปลั๊ก → จุดบัดกรี → อุปกรณ์ป้องกัน/อนุกรม → จุดเก็บประจุ → ตัวควบคุมไฟ → ตัวกรอง → ขาจ่ายโหลด วัดต่อถึงทีละช่วงในสภาพไม่มีพลังงานตามขั้นตอนตรงโมดูล บันทึกค่าจริงและผลที่ผ่านทางขนาน/ชั้นในไม่ได้ ไม่ใช้เสียงบี๊บอย่างเดียวสรุปเป็นเน็ตเดียว

ก่อนระบุค่าลงจุดจริง ต้องมีชื่อเน็ต แพด ขา/ทิศแพ็กเกจ กราวด์อ้างอิง สภาวะทดสอบ เครื่องมือ และแหล่งเกณฑ์ครบ รูยึด/ตัวถัง/แท็บกำลังไม่เป็นกราวด์โดยอัตโนมัติ พิกัดคาปาซิเตอร์และค่าตัวต้านทานไม่ใช่แรงดัน rail

## สำหรับ AI ทำงานต่อ

ผู้ใช้ไม่ทราบรุ่นรถ จึงวิเคราะห์จากข้อมูลที่มีโดยไม่ถามข้อมูลเดิมซ้ำ อย่าอนุมานว่ากล่องเหล่านี้เป็น 1KD/2KD หรือเกี่ยวกับ P0093 จากตำแหน่งโฟลเดอร์เดิม ต้องอ่าน catalog และผลตรวจ ยึดชื่อกล่อง 01–07 ให้คงที่ รักษาไฟล์ originals และแยกความเห็น/ข้อมูลเอกสาร/ผลวัดจริง

หากได้รับภาพมาโครหรือฉลากเพิ่ม ให้จับคู่ภาพกับหมายเลขกล่องเดิมก่อนอัปเดต ห้ามแปลงค่าตัวอย่างในแผ่นสอนเป็นค่าจริงบนภาพ ใช้ทีมวิเคราะห์กับผู้ตรวจอีกคนก่อนอนุมัติจุดวัดมีไฟ อัปเดตเอกสารสถานะและ hash เมื่อเปลี่ยน PDF

สร้างใหม่ด้วย bundled Python: `build_atlas.py` แล้ว `add_schematics.py` จากนั้น bundled Node: `render.cjs` สคริปต์รับภาพจาก Temp ของเครื่องเดิม ถ้าย้ายเครื่อง ให้ปรับให้ชี้สำเนา originals ที่รักษาไว้ ไม่สร้างภาพแผงวงจรขึ้นแทนต้นฉบับ
