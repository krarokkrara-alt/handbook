# รู้จักอุปกรณ์บน ECU — เอกสารประกอบคอร์ส

[อ่านหนังสือ PDF 26 หน้า](output/ECU_Components_Course_Handout.pdf) · [ต้นฉบับ HTML](handout.html) · [ทะเบียนภาพและสิทธิ์](photo_manifest.json)

เอกสารพื้นฐานสำหรับผู้เรียนก่อนอ่านวงจร ECU ใช้ภาพถ่ายจริงของชิ้นส่วนตัวอย่าง 12 ภาพ ควบคู่ภาพขยายจากบอร์ดที่ผู้ใช้ส่ง และสัญลักษณ์วงจรที่วาดเพื่อสอน ไม่มีภาพชิ้นส่วนที่สร้างด้วย AI

ครอบคลุม R แบบแท่งและ SMD, shunt, L/ferrite, C เซรามิกและอิเล็กโทรไลต์, D/TVS, LED, BJT, MOSFET, IC, crystal, connector/via, fuse และกราวด์ พร้อมหลักเลือกโหมดมิเตอร์ แบบฝึกหัด ใบงาน และแนวคำตอบ

## หลักการเขียนและการสอน

1. ให้ผู้เรียนดูภาพจริง เทียบสัญลักษณ์ อ่านรหัส แล้วเลือกวิธีตรวจตามชนิดอุปกรณ์
2. แยกสิ่งที่มองเห็น สิ่งที่อนุมาน และสิ่งที่ต้องยืนยันด้วย datasheet หรือผลวัดจริง
3. ภาพชิ้นเดี่ยวเป็นตัวอย่างรูปร่าง ไม่ใช่อะไหล่ทดแทนที่แนะนำสำหรับ ECU ในโครงการ
4. ไม่เดา pinout หรือแรงดันบนแพดจริงจากรูปทรง IC ไม่ใช้ค่าทนแรงดัน C เป็นค่าไฟเลี้ยง
5. วงจรตัวอย่างเป็นวงจรสอน ไม่ใช่ผัง OEM ของกล่องใด ค่าตัวอย่างใช้ได้เฉพาะเงื่อนไขที่กำกับ
6. สอนข้อจำกัดของการวัดในวงจร เช่น ทางขนาน ค่า DC ของ ferrite และ ESR/การรั่วที่มิเตอร์พื้นฐานยืนยันไม่ได้
7. แยกพลังงานและจัดการประจุตามขั้นตอนก่อนวัด Ω/diode/continuity/capacitance ห้ามนำโพรบแตะ die หรือ bond wire ของโมดูลเปลือย

## สำหรับ AI ที่มารับงานต่อ

อ่าน README นี้, `components-review-notes.md`, `photo-validation.md` และรายงานตรวจฉบับสุดท้ายก่อนแก้ไข เก็บภาพเดิมและเครดิตไว้ ห้ามเปลี่ยนภาพตัวอย่างให้กลายเป็นหลักฐานว่าชิ้นนั้นติดตั้งใน ECU จริง ห้ามเพิ่มค่าตัวเลขเฉพาะรุ่นโดยไม่มีเอกสารตรงเบอร์และเงื่อนไขวัด

แก้เนื้อหาใน `build_handout.py` แล้วสร้าง `handout.html` ใหม่ ใช้ `render_handout.cjs` สร้าง PDF จากนั้นแปลง PDF เป็นภาพและเปิดตรวจทุกหน้าที่เปลี่ยน ตรวจจำนวนหน้า ภาพหาย อักษรไทย สัญลักษณ์ และเครดิต ก่อนปรับ `QA_STATUS.json` ให้ตรง hash ของไฟล์ส่งมอบ ห้ามอ้างว่าผ่านการตรวจจากไฟล์คนละรุ่น

`photos/` เก็บภาพจริงที่ใช้ เอกสารนี้พึ่งภาพบอร์ดและแผ่นวงจรในโครงการแม่ จึงควรดาวน์โหลดโครงการทั้งชุดหากต้องการแก้ HTML แบบออฟไลน์ PDF เปิดอ่านได้โดยลำพัง รายงานเอเจนต์เป็นการตรวจเนื้อหาและรูปเล่ม ไม่ใช่การทดลองฮาร์ดแวร์หรือการรับรองจากผู้ผลิต

## การใช้ภาพ

ระบุผู้สร้าง แหล่งต้นฉบับ และสัญญาอนุญาตใต้ภาพทุกจุดและท้ายเล่ม ภาพภายนอกใช้สิทธิ์ตามแต่ละรายการในทะเบียนภาพ ภาพจากผู้ใช้เป็นภาพอ้างอิงของโครงการ ไม่ประกาศสิทธิ์แบบเปิดแทนเจ้าของภาพ การปรับขนาดเพื่อจัดหน้าไม่เปลี่ยนภาพต้นฉบับ
