## ตรวจเครดิตเทียบแหล่งคัดเลือก

- resistor, ceramic, electrolytic, mosfet, LED: manifest ระบุ Evan-Amos และ Public domain สอดคล้องชุดภาพที่ผู้ประสานงานอ่านต้นทางไว้
- inductor: Peripitus / CC BY-SA 4.0 ตรงกับหน้าต้นทางและไฟล์คัดเลือก
- diode: Zxelt / CC0 ตรงกับหน้าต้นทางและไฟล์คัดเลือก
- BJT: Suyash Dwivedi / CC BY-SA 4.0 ตรงกับหน้าต้นทางและไฟล์คัดเลือก
- SMD resistor: 01x07x2022000 / CC0 ตรงกับหน้าต้นทางและไฟล์คัดเลือก
- IC die: Epop / CC0 ตรงกับหน้าต้นทางและไฟล์คัดเลือก แต่คำอธิบายต้นทางสั้นเกินกว่าจะบอกหน้าที่วงจร
- **คริสตัล:** manifest ใช้ author_html = “me” ตามช่องเดิมของหน้า Commons; เครดิตที่คนอ่านเห็นต้องใช้ **FDominec** ตามผู้สร้าง/ผู้อัปโหลดในประวัติหน้า ไม่พิมพ์ “ภาพ: me”

## เงื่อนไขบังคับก่อนลง PDF

1. แก้การใช้ ic.jpg ให้ชัดว่าเป็นภาพภายใน die หรือแทนด้วยภาพชิปบนบอร์ดของผู้ใช้สำหรับหัวข้อแพ็กเกจ
2. ใต้ภาพทุกภาพมีชื่อผู้สร้าง ลิงก์ File page และสถานะใบอนุญาต; ภาพ CC BY-SA มีลิงก์ license ที่คลิกได้และแยกสิทธิของภาพออกจากข้อความเอกสาร
3. คงภาพทั้งภาพตามแผนผู้ประสานงาน ไม่ครอป/แต่งภาพหรือทับคำอธิบายลงไฟล์ต้นฉบับ การย่อใน layout ให้รักษาสัดส่วน และบอกว่าปรับขนาดเพื่อจัดหน้าเท่านั้น
4. ไม่อ้างภาพตัวอย่างเหล่านี้เป็นอุปกรณ์ที่ถอดจาก ECU ของผู้ใช้ ไม่ย้ายเบอร์/พิกัดของรูปไปใส่จุดบนบอร์ด
5. ภาพคริสตัลใช้ขนาดพอเหมาะ ไม่ขยายจนพร่า; ภาพไดโอดไม่ใช้เป็นแบบฝึกอ่านข้อความเบอร์เต็ม; ภาพ LED ไม่ใช้ขาสั้น/ยาวในรูปเพื่อชี้ขั้ว
6. หลังจัดหน้า ต้องเปิดดู PDF จริงเพื่อตรวจภาพไม่ยืด/ตัดหาย เครดิตอ่านได้ และรูปสอดคล้องคำอธิบาย การตรวจไฟล์ภาพนี้ยังไม่ใช่การผ่าน QA รูปเล่ม

ไม่มีการแก้ builder, manifest หรือภาพต้นฉบับในการตรวจรอบนี้
