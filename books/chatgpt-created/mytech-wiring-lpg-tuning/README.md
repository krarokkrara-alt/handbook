## สิทธิ์และข้อจำกัด

เครดิตภาพและใบอนุญาตอยู่ใต้ภาพและใน photo-credits.json ภาพหน้าจอโปรแกรมเป็นส่วนคัดจากเอกสารผู้ผลิตเพื่ออธิบาย/วิจารณ์ ไม่ใช่ภาพสิทธิ์เสรีและไม่อยู่ภายใต้ใบอนุญาตรวมของ repository นี้ ชื่อผลิตภัณฑ์ไม่แสดงการรับรองจากผู้ผลิต

ค่าตัวอย่างและวงจรหลักการไม่ใช่ pinout หรือแผนที่จูนกลาง ต้องใช้ข้อมูลตรงรุ่น การตรวจเอกสารไม่เท่ากับการตรวจรถจริง
